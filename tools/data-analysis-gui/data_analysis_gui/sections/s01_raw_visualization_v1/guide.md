# S01 · Raw data visualisation（原始数据可视化）

**一句话总结：**核查事件对齐活动及指定方向响应在整场记录中的变化，并量化 trial 筛选、方向覆盖和记录连续性。

本节回答：**原始神经计数在 trial 里长什么样？筛选保留了哪些 trial、为什么排除了其余的？**
数据：Topbar 筛选后的方向队列（direction cohort）。神经数据是每 20 ms 一帧、512 个传输通道的 2 bit 计数（0/1/2/3，3 表示 ≥3），
名义发放率 = 计数 / 0.020 s。时间基于 LSL 接收时间。事件对齐横轴以所选事件（默认 T_TRIAL_START）为零，整场时间纵轴以首个神经接收帧为零。

在「电极 ID」输入框中用逗号或空格分隔多个 ID，运行后两类 raster 和 trial average 各自按输入顺序用 Prev / Next 翻页，每页一个电极。默认 `0` 自动选择方向调制最强的一个电极。

阅读约定：以下按 subplot 的位置/标题逐项说明；重复的方向、电极、decoder 或记录面板逐个适用对应条目，双轴/色条与主面板合并解释。质量标准区分配置阈值、统计证据与描述性限制，历史数值不作为通用合格线。

勾选「计算所有活跃电极」时，按记录列顺序选用整份记录中至少有一帧计数非零的电极。各电极图组可用 Prev / Next 翻页。

## 图 1：Eight-direction raster

### 计算公式
**符号**
- `t`：trial 编号（第几个 trial）。
- `t₀`：第 t 个 trial 的对齐时刻，即该 trial 的 T_TRIAL_START 接收时间（参数「对齐事件」选 target_acquired 时改为首次命中时刻），单位 s。
- `f`：一帧神经数据；`τ_f`：这一帧的接收时间（s）；`c_f`：这一帧在所选电极上的计数（0、1、2、3，3 表示 ≥3）。
- `[a, b)`：分析窗口，相对 t₀ 的起止时间（默认 a = 0.2 s，b = 1.2 s）。
- `N_t`：第 t 个 trial 的分析窗口里收到的帧数。
- `Δ`：每帧的积分时长，固定 0.020 s。
- `d`：目标方向（0°、45° … 315°）；`T_d`：方向为 d 的 trial 集合，|T_d| 是其中的 trial 数。

**步骤**
1. 竖线位置：对每个 trial 的每一帧，若 c_f > 0，就在横坐标 x = τ_f − t₀ 处画一条竖线，竖线大小 ∝ c_f。
   意思是：每条竖线代表「这 20 ms 里该电极有发放」，越靠右越晚。
2. 单个 trial 的窗口平均发放率：r_t = (Σ_{窗口内的帧} c_f) ÷ (N_t × Δ)，单位 Hz。
   意思是：把窗口内的计数加起来，再除以窗口实际收到数据的时长。
3. 中间极坐标图：每个方向的平均 r̄(d) = (Σ_{t∈T_d} r_t) ÷ |T_d|。
   意思是：同一方向所有 trial 的窗口发放率取平均。
4. 电极 ID 填 0 时自动选通道：对每个通道做 r_t 的单因素 ANOVA（因素 = 方向），取 F 值最大的通道（F 的定义见 S05）。

### 结果解读
- **外圈各方向 raster**：每个方向面板逐行读取 trial 的计数事件，比较窗口内密度、响应时序和 trial 间一致性。
- **中心方向调谐极坐标图**：半径为该电极各方向窗口平均发放率，观察偏好方向及相邻方向的变化。

### 质量评价标准
- **外圈各方向 raster**：有事件不能等同于方向调谐；空白需区分无发放与缺帧，密集 code 3 需结合 S02 检查截断，方向样本量需同时报告。
- **中心方向调谐极坐标图**：明显花瓣仅为当前样本的描述；自动选择最大 F 通道带有选择偏倚，显著性及泛化需另用 S05/S09 验证。

## 图 2：Direction raster over recording time

「整场 raster 方向」选择一个方向。图中保留该方向所有通过筛选且能对齐的 trial，不受「每方向 raster 最多 trial 数」限制。纵轴从上到下是 trial 开始距首个神经接收帧的分钟数，每个电极使用相同的整场时间轴。

### 计算公式

**符号**
- `s_t`：trial 开始时间。`s_0`：首个神经接收帧的时间。`a_t`：所选对齐事件的时间，单位均为秒。
- `C_t`：对齐窗口内存储计数之和。`N_t`：窗口内收到的帧数。`Δ`：每帧积分时长，单位秒。

**步骤**
1. 左图每个 trial 的纵坐标为 `(s_t − s_0) / 60`，每个非零计数帧的横坐标为其接收时间减 `a_t`。灰线标出 trial 行，彩色竖线大小随存储计数变化。
2. 右图在同一 trial 行画窗口平均观测发放率 `C_t / (N_t × Δ)`。`N_t = 0` 时画灰色叉号。导出的 `trials` 表记录实际收到的帧数、trial 编号及 block。

### 结果解读

- **A 整场时间 raster**：沿纵轴找活动密度、响应起点或持续时间开始改变的分钟数。翻到其他电极的同一分钟，检查变化是否同时出现。
- **B 逐 trial 平均发放率**：沿纵轴看点是否持续向左或向右偏移。左图若出现响应时序变化而右图点位接近，提示窗口内的活动可能发生了时间重分布。

### 质量评价标准

- **A 整场时间 raster**：稀疏的灰线表示该段可用 trial 少。判断变化前比较附近多个 trial，并用 S03 或导出的收帧数核查缺帧。
- **B 逐 trial 平均发放率**：优先比较收帧数接近的 trial。灰叉表示缺失，横轴 0 Hz 的实点表示有帧且计数为零。图用于目视定位变化，变化点未经统计检验。

## 图 3：Eight-direction trial average

### 计算公式
**符号**
- `w`：PSTH 的时间 bin 宽度（参数「PSTH bin」，默认 0.05 s）；`k`：第几个 bin，覆盖 [t₀ + 起始时间 + k·w, t₀ + 起始时间 + (k+1)·w)。
- `C_{t,k}`：第 t 个 trial、第 k 个 bin 内所选电极的计数之和；`N_{t,k}`：该 bin 内收到的帧数。
- `Δ`：每帧积分时长 0.020 s。
- `T_d`：方向为 d 的 trial 集合；`m_{d,k}`：方向 d、bin k 上有有效数据（N_{t,k} > 0）的 trial 数。
- `SD`：标准差；`SEM`：均值的标准误。

**步骤**
1. 单个 trial、单个 bin 的发放率：r_{t,k} = C_{t,k} ÷ (N_{t,k} × Δ)；N_{t,k} = 0（这一段没收到神经数据）时记为缺失，不参与平均。
2. 方向 d 的 PSTH：均值 r̄_{d,k} = 对 T_d 中有效 trial 的 r_{t,k} 取平均。
3. 误差带：SEM_{d,k} = SD_{d,k} ÷ √m_{d,k}。
   意思是：trial 越多、trial 间差异越小，误差带越窄。
4. 中间图：先对 512 个通道的 r_{t,k} 取平均，再按方向做第 2 步，得到群体平均 PSTH。

### 结果解读
- **外圈各方向 PSTH**：各面板展示单电极对应方向的平均时间响应及 SEM，分别检查基线、响应起点、峰值和缺失 bin。
- **中心群体均值**：比较所有 512 通道平均活动的方向曲线，识别全局活动变化。

### 质量评价标准
- **外圈各方向 PSTH**：误差带相对响应幅度较窄且有效 trial 数充分时估计较稳定；基线已分离、共同突变或长缺口需核查，SEM 不是 trial 的分布范围。
- **中心群体均值**：曲线重叠不代表群体无方向信息，分离也可能来自整体增益；需结合 S04 的通道模式与增益控制，不能要求群体均值必须分离。

## 图 4：Filtered trial overview

### 计算公式
**符号**
- trial：由事件流重建的一次尝试，从 T_TRIAL_START 到 T_TRIAL_END；中间的 T_TARGET_ACQUIRED 表示命中，MISS 表示失败。
- 时长 = T_TRIAL_END 时刻 − T_TRIAL_START 时刻（s）。
- 标准：Topbar「筛选设置」中的 8 条筛选标准（Incomplete、结局、方向标签、计时、窗口、神经覆盖、block、速度 bin）。
- 主要原因：一个 trial 可能同时违反多条标准，按上面的固定优先级取第一条，作为它被排除的主要原因。
- 方向队列：通过标准 1–7 的 trial；速度队列：方向队列中再通过速度 bin 质量（标准 8）的 trial。
- flag：只做标记、不排除的情况（过快、命中早于窗口结束）。

**步骤**
1. 对每个 trial 逐条检查标准，记 pass / fail / flag；用 cursor 流在 active_trial = 1 时的 trial/block 编号核对事件流重建是否一致。
2. 左上：红色条 = 每种主要原因的 trial 数（每个被排除的 trial 只计一次）；橙色条 = 留在方向队列、但因速度 bin 质量离开速度队列的 trial 数；蓝色条 = 各类 flag 的 trial 数。
3. 右上：每个方向的 trial 数，灰 = 有方向标签，浅色 = 方向队列，深色 = 速度队列。
4. 下方：每个 trial 一个点，横坐标 = 开始时间（相对第一个 trial，s），纵坐标 = 时长；红 × = 被排除的 trial；粉色竖带 = 超过 0.5 s 的神经接收空档。

### 结果解读
- **左上排除原因与标记**：按主要原因读取排除数量，单独读取速度质量损失和不排除的 flags。
- **右上各方向样本量**：分别比较有标签、方向队列和速度队列在八个方向上的保留量。
- **下方时长与接收缺口**：按记录时间查看 trial 时长、被排除点与神经缺口的重合。

### 质量评价标准
- **左上排除原因与标记**：排除应可追溯到预先设定规则；flags 不等于失败，多个标准的总次数不能当作独立 trial 数。
- **右上各方向样本量**：使用当前配置的每方向最少样本标准；明显不平衡会改变统计功效和指标解释，不以历史记录的固定 trial 数作为合格线。
- **下方时长与接收缺口**：排除或长时 trial 的时间聚集应结合 S03 核查；任务暂停不自动等于故障，session 资格以当前配置及覆盖情况判定。

## 图 5：Task success rate

### 计算公式

**符号**

- S 为命中数，N 为有明确结局的完整试次数（命中 + MISS，含超时）。横坐标为试次开始时间减去首个神经帧时间，以分钟计。

**步骤**

1. 按开始时间排列 Topbar 筛选前有明确结局的完整试次。
2. 在每个试次开始时间，用截至该试次的最近 40 次有效试次计算总体及各方向的 S / N。开头不足 40 次时用已有试次。

### 结果解读

- **成功率时间曲线**：Overall 为滚动窗口内的总体成功率，其余八条线对应八个目标方向。每个点包含该试次的最终结果，横坐标取试次开始时间。

### 质量评价标准

- **成功率时间曲线**：窗口内没有试次的方向留空。比较方向时同时查看导出表中的试次数。总体曲线包含有明确结局但缺少方向标签的试次。

## 图 6：Neural activity stability

在 S01 参数中勾选「生成全通道稳定性图册」后生成此图册，默认预览跳过。

### 计算公式

**符号**

- `t` 为试次开始距首个神经帧的分钟数，`r` 为所选对齐窗口内该电极的平均发放率（Hz）。

**步骤**

1. 对每个保留且可对齐的试次，按图 2 的方法计算所有电极的 `r`。
2. 按记录列顺序每 64 个电极分一页，排成 8×8 小图。每个小图叠加该电极的八条方向曲线，各图共享时间轴，发放率纵轴独立。
3. 按电极和方向导出中位数、绝对中位差（MAD）和 Theil–Sen 斜率。MAD 至少需两个点，斜率至少需三个不同的试次时间。

### 结果解读

- **发放率叠加曲线**：横轴为 `t`，纵轴为 `r`，颜色区分方向。用 Prev / Next 切换电极组，可从逐试次导出表按电极 ID 查具体曲线。

### 质量评价标准

- **发放率叠加曲线**：包含有调谐和无调谐的记录电极。窗口内无神经帧时曲线留空。比较时同时看有效试次数和所选对齐窗口。

## 注意事项
- 本节只描述数据，不做统计检验；方向调制是否显著见 S05（ANOVA），时间响应见 S06（PSTH）。
- 所有阈值在「筛选设置…」中修改；改动后结果签名变化，会重新计算。
