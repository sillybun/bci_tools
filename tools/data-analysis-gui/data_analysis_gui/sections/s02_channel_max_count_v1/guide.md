# S02 · 通道稳定性分析

**一句话总结：**描述传输电极的计数活跃度、上限截断及空间分布，区分低活动、频繁饱和与异常聚集而不直接等同于通道优劣。

本节回答：**512 个传输通道各自有没有信号、信号强到什么程度、有多少帧被 2 bit 上限截断（饱和）？这些通道在阵列上的什么位置？**
数据：spike_counts 原始帧，不做平滑或换算。参数「统计范围」= whole_recording（全部帧，不做 trial 筛选）或
included_trials（只用 Topbar 筛选保留的 trial 在 [T_TRIAL_START, T_TRIAL_END] 内接收到的帧）。
每帧每通道是一个 2 bit 编码 c ∈ {0, 1, 2, 3}，3 表示「≥3 个事件」；若出现 > 3 的值也按 3 计。配置窗口 Δ = 20 ms。
电极位置有两种画法：Physical layout（物理布局，布局 xlsx 存在时，位置 1 在下、128 在上，列从左到右）和 Default layout（128×8 电极 ID 网格，
按列排：电极 e 在第 (e−1)//128+1 列、第 (e−1)%128+1 行）。灰色 = 该电极不在本记录传输的 512 个通道中（1024 个位点只传 512 个）。


阅读约定：以下按 subplot 的位置/标题逐项说明；重复的方向、电极、decoder 或记录面板逐个适用对应条目，双轴/色条与主面板合并解释。质量标准区分配置阈值、统计证据与描述性限制，历史数值不作为通用合格线。

## 图 1：Channel saturation zones

散点横轴是平均发放率 (Hz)、纵轴是饱和度 (%)（均为 symlog）。电极图、散点和柱状图共用一份图例。图例中 fr 为平均发放率，sat 为饱和度。

### 计算公式
**符号**
- `j`：传输通道（存储列）编号，1–512；每个通道对应一个电极 ID `e`（1–1024）。
- `f`：统计范围内的一帧（每帧 20 ms）；`N`：统计范围内的总帧数；`c_j(f)`：第 f 帧在通道 j 上的编码，0–3（3 表示 ≥3）。
- `Δ`：每帧时长 0.020 s。
- `r_j`：通道 j 的平均发放率（Hz）= (Σ_f c_j(f)) ÷ N ÷ Δ，被 2 bit 上限截断，是真实发放率的下界。
- `s_j`：通道 j 的饱和度 = (c_j(f) = 3 的帧数) ÷ N × 100%。
- `max_j`：通道 j 在统计范围内的最大编码，0–3。
- `rate_min`：无信号阈值，默认 0.5 Hz；`sat_ok`：轻度截断上限，默认 1%；`sat_bad`：重度截断下限，默认 5%；`burst_ratio`：爆发判定倍数，默认 3。
- `X`：假想的随机（Poisson）发放者每帧的真实事件数；`λ`：每帧平均事件数（不是 Hz：λ = 真实发放率 × Δ，例如 20 Hz → λ = 0.4）。
- `p_k`：P(X = k) = e^(−λ) × λ^k ÷ k!，k = 0、1、2。
- `symlog`：对称对数轴，1 Hz / 0.01% 以下按线性画、以上按对数画。

**步骤**
1. 画点：每个通道放在 (x = r_j, y = s_j)，两轴都是 symlog。
   意思是：用 symlog 而不是 log，是因为很多通道 s_j = 0（从没到过 3）、silent 通道 r_j ≈ 0，log 轴画不出 0；symlog 在 0 附近是线性的，这些点仍留在图上。
2. 分区（描述截断程度，不是通道好坏）：
   - 静默：r_j < rate_min，或 max_j = 0。
   - 有信号（r_j ≥ rate_min）时，按 s_j ≤ sat_ok、sat_ok < s_j ≤ sat_bad、s_j > sat_bad 分三档。
   意思是：先排除没信号的，再按有多少帧顶到上限分三档。
3. silent 再拆成两部分：max_j = 0（黑色，一个事件都没有：死通道 / 断线 / 空列，散点图中画为原点处的黑 ×）和其余有零星事件的 silent（灰色）。
4. Poisson 参考曲线：横坐标 = (3 − 3p₀ − 2p₁ − p₂) ÷ Δ，纵坐标 = (1 − p₀ − p₁ − p₂) × 100%，λ 从很小扫到很大连成黑色曲线。
   意思是：真实事件数是 X，存储的是 min(X, 3)；曲线给出一个随机发放者在每个观测发放率下「应该」有多少帧到 3。
   例如观测 20 Hz → λ ≈ 0.40，预期饱和度 0.8%，观测均值只低估 0.2%；40 Hz → 4.9%，低估 1.4%；60 Hz → 13%，低估 4%。
5. 爆发标记（bursty，品红框 / 圈）：s_j > sat_ok 且 s_j > burst_ratio × E_j，其中 E_j = 同样观测发放率下 Poisson 曲线给出的饱和度（至少按 1 帧计）。
   意思是：同样的平均发放率，这个通道顶到上限的次数远多于随机发放者，事件扎堆出现。
6. 电极图：每个电极按分区着色（绿 / 黄 / 红 / 灰 / 黑），品红框 = bursty。
7. 下方柱状图：每根柱 = 一组通道，从下往上按共享图例的前五项堆叠；标签 = 通道数与该柱内百分比；
   虚线框 = silent 两部分合计；柱顶粗体 = 该组总数；柱下 = 该组 bursty 数。
   第一根柱 = 全部传输通道；当天目录有 configs.ini 时，再按 good / uncertain / bad（以及不在任何列表的 unlisted）各画一根。

### 结果解读
- **物理布局与默认布局**：两个布局面板表示相同电极分区，分别按真实空间和电极 ID 定位 silent、不同饱和层及 bursty 标记。
- **发放率与饱和度散点**：每点一通道，比较观测率、饱和度、配置分区和 Poisson 参考曲线。
- **分区组成柱状图**：读取全部通道及可用配置层级内各分区数量、比例、零事件和 bursty 数。

### 质量评价标准
- **物理布局与默认布局**：灰色未传输不是零；空间聚集需核对布局、连接及配置，不能仅凭热点或颜色认定坏通道。
- **发放率与饱和度散点**：分区阈值为用户配置的描述规则；偏离 Poisson 是复查线索，不是伪迹诊断，饱和率高也可能只是活动较高。
- **分区组成柱状图**：同时看分母与静默占比；good 标签和信号质量不一致时需核对配置时间，不能要求所有层级服从固定比例。

## 图 2：Maximum code and code distribution

电极图颜色是每个电极出现过的最大编码 (0–3)，直方图横轴是某编码的帧占比、纵轴是通道数，用来看哪些通道有信号、信号最强到几。

### 计算公式
**符号**
- `j`：传输通道编号，1–512。
- `f`：统计范围内的一帧（每帧 20 ms）；`N`：统计范围内的总帧数；`c_j(f)`：第 f 帧在通道 j 上的编码，0–3（3 表示 ≥3）。
- `max_j`：通道 j 在统计范围内的最大编码，0–3。
- `k`：编码取值，0、1、2、3。
- `f_jk`：通道 j 中编码为 k 的帧所占比例（0–1）。
- `zoom_n`：放大面板的通道数，参数，默认 60。

**步骤**
1. 最大编码：max_j = max_f c_j(f)。
   意思是：在统计范围内的所有帧里，取通道 j 出现过的最大编码。
2. 电极图颜色：max_j = 0 黑、1 黄、2 橙、3 红；未传输的电极画灰色；图例给出各最大值的通道数与未传输电极数（1024 − 512）。
3. 编码比例：f_jk = (统计范围内 c_j(f) = k 的帧数) ÷ N，且 f_j0 + f_j1 + f_j2 + f_j3 = 1。
   意思是：数一数通道 j 有多少帧是 0、1、2、3，再除以总帧数。
4. 右上左：按 max_j 统计通道数。
5. 右上右（组成图）：每个有事件的通道画 f_j3、f_j2、f_j1 自底向上堆叠（最稀少的 code 3 贴底；剩下的部分就是 f_j0）；
   通道按非零占比 1 − f_j0 从大到小排序；max_j = 0 的通道不画，只在标题中计数。
   意思是：外轮廓是每个通道的活跃程度，贴底的红 / 橙高度可以直接比较。
6. 中间（放大）：f_j3 最高的前 zoom_n 个通道（并列时按 f_j2），只画 f_j3（红，贴底）与 f_j2（橙），x 轴标电极 ID。
7. 下排 4 个图：对每个 k，把所有传输通道的 f_jk 做直方图（从 0 到最大值分 40 个等宽 bin，y 轴对数）。

### 结果解读
- **物理布局与默认布局**：比较相同电极出现过的最大编码，定位整段零事件区域。
- **最大编码通道计数**：读取 max code 0、1、2、3 各有多少传输通道。
- **非零编码组成**：按非零比例排序，分别观察 code 1、2、3 的组成及活跃长尾。
- **高饱和通道放大**：读取列出的电极 ID，比较 code 2 与 code 3 占比。
- **下排各 code 比例直方图**：四个面板分别显示各通道在编码 0、1、2、3 上的帧比例分布。

### 质量评价标准
- **物理布局与默认布局**：最大编码受记录长度影响；黑色只能证明范围内未观测到事件，不能单凭此图诊断断线，灰色表示未传输。
- **最大编码通道计数**：各组总数应等于传输通道数；最大值 3 只表示至少一次达到计数上限，不等于频繁饱和。
- **非零编码组成**：组成比例须与统计范围一致；多 code 0 不自动代表无用，需结合任务调制和下游验证。
- **高饱和通道放大**：检查是否少数电极主导以及是否与 bursty 对应；不能只据单个红柱调整阈值。
- **下排各 code 比例直方图**：四类比例对每个通道应合计为 1；code 3 右尾提示截断风险，code 0 近 1 提示低活动，均无跨数据集统一合格比例。

## 图 3：Saturation per electrode

电极图颜色是饱和度（编码 3 的帧占比 %），排序曲线横轴是通道名次、散点横轴是平均发放率，两者纵轴都是饱和度，用来看哪些通道、多少通道经常顶到 2-bit 上限。

### 计算公式
**符号**
- `j`：传输通道编号，1–512。
- `N`：统计范围内的总帧数；`c_j(f)`：第 f 帧在通道 j 上的编码，0–3（3 表示 ≥3）。
- `Δ`：每帧的配置积分时长，0.020 s。
- `s_j`：通道 j 的饱和度，即编码为 3 的帧所占百分比（%）。
- `r_j`：通道 j 的平均发放率（Hz），被 2 bit 上限截断，是真实发放率的下界。
- `sat_ok`、`sat_bad`：两条饱和度参考线，参数，默认 1% 和 5%。
- `p99.5`：第 99.5 百分位数（linear 色标的上限）。

**步骤**
1. 饱和度：s_j = (c_j(f) = 3 的帧数) ÷ N × 100%。
   意思是：通道 j 有多大比例的帧顶到了上限 3。
2. 电极图色标：log 模式下从 max(1 帧对应的分辨率, 非零 s_j 的第 1 百分位) 到最大值，低于这个下限（含 0）画浅蓝；linear 模式为 0 到 p99.5。
   意思是：log 让很小的饱和度也能分出深浅。
3. 右上排序曲线：把 s_j 从大到小排列画出（对数 y 轴，s_j = 0 的不画）；在 sat_ok、sat_bad 处画线，图例给出超过各线的通道数。
   意思是：看有多少通道饱和超过 1% 和 5%。
4. 中间散点的横坐标：r_j = (Σ_f c_j(f)) ÷ N ÷ Δ。
   意思是：每帧平均编码除以 20 ms，得到每秒事件数。
5. 上限竖线：3 ÷ Δ = 150 Hz；点的颜色 = max_j（见图 2）。
   意思是：任何通道的读数都不可能超过 150 Hz。
6. 下方表格：s_j 最高的电极（电极 ID、存储列、s_j、r_j），完整前 top_n 个（参数「饱和度 Top-N 表行数」）见表 top_saturated。

### 结果解读
- **物理布局与默认布局**：定位编码 3 的帧百分比，按各自色条识别热点。
- **排序饱和曲线**：看超过当前 sat_ok、sat_bad 参考线的通道数量及尾部。
- **饱和度与平均率散点**：比较高平均率与高截断的关系，留意低均值但饱和较多的电极。
- **高饱和电极表**：逐行读取电极 ID、存储列、饱和度及均值，定位需要复查的通道。

### 质量评价标准
- **物理布局与默认布局**：线性/对数色标不可按颜色直接比较；零值、缺失及色标下限须区分。
- **排序饱和曲线**：参考线是配置阈值而非生理正常值；频繁截断会压缩幅度，须评估对调谐和解码的实际影响。
- **饱和度与平均率散点**：观测率已被截断，不能估计真实峰值；异常离群需对照时序和原始事件确认。
- **高饱和电极表**：排名不构成自动剔除依据；结合记录时长、配置与 S05/S09 的贡献评价。

## 图 4：Mean rate per electrode

电极图颜色是平均发放率 (Hz)，直方图横轴是发放率、纵轴是通道数，用来看活跃通道在阵列上怎么分布；红框通道饱和严重，读数偏低。

### 计算公式
**符号**
- `j`：传输通道编号，1–512。
- `N`：统计范围内的帧数；`c_j(f)`：第 f 帧在通道 j 上的编码，0–3（3 表示 ≥3）。
- `Δ`：每帧时长 0.020 s。
- `r_j`：通道 j 的平均发放率（Hz）。
- `sat_bad`：重度截断饱和度下限，默认 5%；`s_j`：饱和度（见图 3）。
- `p99.5`：第 99.5 百分位数。

**步骤**
1. 平均发放率：r_j = (Σ_f c_j(f)) ÷ N ÷ Δ。
   意思是：编码 3 按 3 计，所以 r_j 是真实发放率的下界，最大 3 ÷ Δ = 150 Hz。
2. 色标：log 模式下从 max(1 个事件对应的分辨率, 非零 r_j 的第 1 百分位) 到最大值，低于下限（含 0）为白色；linear 模式为 0 到 p99.5。
3. 加框：s_j > sat_bad 的电极加红框。
   意思是：这些电极处在 often saturated 区，发放率读数被上限压低。
4. 右侧直方图：所有传输通道的 r_j，40 个等宽 bin，对数 y；虚线 = 150 Hz 上限。

### 结果解读
- **物理布局与默认布局**：对照平均观测率的空间分布及重饱和框。
- **平均率直方图**：查看低活动比例、主要分布和接近编码上限的尾部。
- **统计文字面板**：结合最小值、分位数、均值和最大值判断直方图是否被少数通道主导。

### 质量评价标准
- **物理布局与默认布局**：所有率都是 2 bit 截断下的下界；布局缺失和无信号不是同一情况，不因高发放率直接判为优质。
- **平均率直方图**：接近 3/帧时长的观测上限意味着幅度信息严重压缩；没有适用于所有记录的最低率或最佳长尾形状。
- **统计文字面板**：均值与中位数差异应结合分布解释；所有统计都仅代表当前选定范围和已传输通道。

## 注意事项
- 2 bit 编码：编码 3 只表示「≥3」，所有发放率都是截断后的下界；饱和越高，低估越严重。
- whole_recording 包括 trial 之间和任务暂停期；included_trials 只反映任务期间，饱和度通常略不同（10-26 run-010 只用保留 trial 时 > 1% 的通道为 6 个）。
- 未传输的电极是灰色（NaN），不是 0；不同天传输的 512 个电极可能不同，跨天比较见 X01。
- 通道是否被 configs.ini 标为 good / uncertain / bad 见 S08；方向调制是否显著见 S05；接收缺口与丢帧见 S03。
