# S04 · 降维分析 PCA UMAP TDR

**一句话总结：**以 PCA 分解主要变异、UMAP 探索局部组织、TDR 检验方向相关结构，并用增益、时间及实测运动学控制限制解释范围。

降维 Overview 按 PCA、UMAP、TDR 分三列，右下角为 TDR 角度误差图；随后每种方法各一页详细主图，后续 Supplementary 保留补充诊断。
输入为顶栏筛选后的方向队列，神经特征是在 T_TRIAL_START + [窗口起点, 窗口终点) 内的平均计数 / 帧时长（Hz）。去掉无有限特征的 trial 和非恒定通道。
PCA 解释变异，UMAP 探索邻域，TDR 检验任务相关结构。时间项使用真实 trial 开始时间减去第一个有效 trial 开始时间（秒），不是 block 内顺序。
所有方向质心图均有同色、仅轮廓无填充的 1 SD 样本协方差椭圆：半轴为协方差特征值的平方根，协方差分母 n−1。它表示 trial 分散程度，不是均值置信区间；二维高斯下约覆盖 39% 概率。少于 3 个有效点或协方差退化时跳过。CSV 记录中心、宽、高和旋转角。


阅读约定：以下按 subplot 的位置/标题逐项说明；重复的方向、电极、decoder 或记录面板逐个适用对应条目，双轴/色条与主面板合并解释。质量标准区分配置阈值、统计证据与描述性限制，历史数值不作为通用合格线。

## 图 1：Dimensionality overview

### 计算公式
**符号**
- X：有限 trial 的非恒定通道窗口平均率；PCA/UMAP 使用全队列 z-score；TDR 使用训练折局部参数。
- g：活跃通道总发放率；τ：真实经过秒数；s_i：PCA 奇异值；PC 解释方差=s_i²/Σs²。
- r：held-out TDR 的 Fisher–Lee 圆形相关；置换 p=(1+#null≥observed)/(1+全部有效置换数)，存在无效重复时不报告 p。

**步骤**
1. 两行三列：第一列 PCA、第二列 UMAP、第三列 TDR。各图复用本次 S04 已计算的结果。
2. A：样本内普通 PC1–PC2；D：去掉每通道与 total rate 的线性关联，残差逐通道重新 z-score 后重新拟合的样本内 Residual PC1–PC2。两个面板轴标签各写自身解释方差；普通 PCA 分母为原始标准化特征方差，残差 PCA 分母为重新标准化的残差特征方差，不能直接比较为同一原始方差比例。方向 centroid 连线与无填充 1 SD 椭圆保留。方差谱、总率/时间相关仍在详细 PCA 页。
3. B：全队列无监督 UMAP 按方向着色；E：同一坐标、同一范围按 block 着色。不传方向标签拟合，也不把坐标原点当成生理中心。关闭 UMAP 时上下两格均明确显示 disabled。
4. C：训练 block 拟合、±1 block purge 的 held-out TDR cos/sin 投影；F：复用 TDR 详情页的角度误差散点图，扣除由测试标签估计的旋转偏移。置换零分布和 p 见 TDR 详情页。
5. 数据不足/置换关闭/无效时明确说明，不以零当成未显著。去增益、额外 PC、邻域保持、折间稳定性及速度控制仍见后续各方法详细页。

### 结果解读
- **A 左上 PCA 投影**：看最大变异平面中方向结构与 trial 散布，读取 PC1–2 方差比例。
- **B 中上 UMAP 方向**：看局部邻域是否出现方向组织，并与正下方 block 着色对照。
- **C 右上 TDR held-out**：看方向结构能否在未参与轴拟合的 trial 上出现。
- **D 左下残差 PCA 投影**：与 A 对照，查看去掉总率线性关联后方向组织是否仍可见；这是重新拟合的残差坐标系。
- **E 中下 UMAP block**：与 B 使用相同位置，检查方向组织是否同时伴随记录时间分层。
- **F 右下 TDR 角度误差**：按目标方向显示每个 held-out trial 的角度误差，虚线标出 ±45°。

### 质量评价标准
- **A 左上 PCA 投影**：样本内分离不是样本外证据，椭圆为散布而非均值置信区间。
- **B 中上 UMAP 方向**：视觉分离不证明非线性编码，远距离、面积与中心没有直接物理解释。
- **C 右上 TDR held-out**：仍需结合置换、折间稳定性和运动学控制，不能直接称为纯运动意图。
- **D 左下残差 PCA 投影**：轴和标准化尺度均不同，视觉分离不能证明解码改善；总率关联也可能包含真实任务信号。本面板是样本内，稳定性另见 held-out 残差 PCA 补充页。
- **E 中下 UMAP block**：block 与方向混杂可造成相似结构，连续色带可来自状态漂移而非真实方向差异。
- **F 右下 TDR 角度误差**：旋转偏移由留出 trial 的目标标签估计，误差用于描述方向读出。

## 图 2：PCA

### 计算公式
**符号**
- X：trial × 活跃通道窗口平均发放率；Z = (X − 通道均值) / 通道标准差。
- s_i、v_i：Z 的奇异值和右奇异向量；score_i = Z·v_i；解释方差比例 = s_i² / Σs²。
- g_t = Σ_c X_tc：trial 总发放率；τ_t：实际经过秒数。
- R_tc = X_tc − mean(X_c) − β_c·(g_t − mean(g))，β_c = Σ(g−mean(g))(X_c−mean(X_c)) / Σ(g−mean(g))²。
- F：方向分组的单因素 ANOVA F；max-F：当前设置的全部 PCA 主成分中最大的 F。

**步骤**
1. 对全部有效 trial 的非恒定通道做 z-score 后 SVD，展示前 20 个 PC 的解释方差和累计方差；PC1–PC2、PC2–PC3 按方向着色，加质心、连线和 1 SD 椭圆。
2. 计算每个显示 PC 与 g、τ 的 Pearson r；PC 的正负号只按总发放率相关方向统一，不预设 PC1 或其他固定 PC 是增益轴。
3. 将每个通道对截距和总发放率回归，残差重新标准化后重新做 PCA。此时为另一套基底，不能把两次 PC1 当成相同轴。
4. 两次 PCA 的方向 F 各自按大小排序比较；用相同的 block 内方向置换，分别得到两套基底的 max-F 零分布及其 95 分位阈值。置换次数为 0 时不画阈值，p 留空。
5. 右下显示残差 PCA 的 PC1–PC2。若残差非恒定通道不足，说明无法生成该平面，不虚构坐标。

### 结果解读
- **A 解释方差谱与累计轴**：柱表示各 PC 比例，右轴曲线表示累计比例，判断线性变异是否集中。
- **B 全队列 PC1–PC2**：比较各方向 trial、质心、连线及 1 SD 轮廓的重叠和排列。
- **C 全队列 PC2–PC3**：检查方向结构是否出现在较低方差轴，和 B 比较。
- **D 增益与时间相关**：对每个显示 PC 分别读取与总率及真实经过时间的 Pearson r。
- **E 去增益前后方向 F**：比较两套重新排序的 F 谱及各自经验 max-F 阈值。
- **F 残差 PCA 投影**：查看逐通道回归总率后重新标准化和 PCA 的方向结构。

### 质量评价标准
- **A 解释方差谱与累计轴**：没有统一合格解释率；最大方差轴不必编码任务，累计比例须与所含 PC 范围一起报告。
- **B 全队列 PC1–PC2**：为样本内描述，不能视为解码准确率；离群点裁剪会注明，质心环形本身不足以证明稳定编码。
- **C 全队列 PC2–PC3**：不预设此平面必为方向平面；轴方差与方向效应必须分开，选择性查看最好看的平面不是独立检验。
- **D 增益与时间相关**：相关不代表原因；最强增益相关 PC 可为任意编号，恒定变量相关不可定义。
- **E 去增益前后方向 F**：两套 PC 基底不同，名次不是同一轴；置换为 0 时无显著性结论，去增益也可能移除真实任务信号。
- **F 残差 PCA 投影**：残差轴不能与原 PC 逐轴对比；结构保留仅为敏感性证据，残差秩不足时不生成平面。

## 图 3：UMAP embedding

### 计算公式
**符号**
- Z：与 PCA 相同的标准化活跃通道特征，不预先截断 PCA。
- U：UMAP 二维坐标；k_fit：拟合邻居数；k_eval：评价邻居数。
- T(k)：邻域可信度 trustworthiness，范围 [0,1]，惩罚低维近邻中原空间并非近邻的点。

**步骤**
1. 无监督拟合二维 UMAP：欧氏距离、随机初始化、固定 seed、n_jobs=1、spread=1；min_dist 可调，k_fit=min(设置值, trial 数−1)。方向和 block 不参与拟合。
2. 左上按方向着色，绘制质心、连线、1 SD 椭圆；右上按 block 着色；左下按总发放率着色，三图使用完全相同的坐标。
3. 在 k_eval=3、5、10、15（须小于评价 trial 数的一半）计算 T(k)，以 PCA 前两维作参照。最多评价 2000 个 trial；超过时用固定种子抽样并导出评价 trial_id。嵌入仍在全部 trial 上拟合。
4. 保存全部 trial 的 UMAP 坐标、质心、状态着色值、实际参数和库版本，以及邻域质量数据。

### 结果解读
- **左上方向着色**：观察同一方向 trial 的局部相邻性及质心轮廓，方向标签不参与拟合。
- **右上 block 着色**：用相同坐标检查早晚 block 的混合、分区或径向变化。
- **左下总率着色**：用相同坐标检查嵌入组织是否对应整体群体增益。
- **右下邻域可信度**：比较各评价 k 下 UMAP 与 PCA2 的 trustworthiness，读取实际评价样本数。

### 质量评价标准
- **左上方向着色**：分群和椭圆仅描述该嵌入，不能据此证明非线性编码；距离/面积无原始空间的直接物理意义。
- **右上 block 着色**：时间相关结构提示漂移线索，不自动等于发放增强、疲劳或噪声增加。
- **左下总率着色**：颜色梯度不是因果归因，需与 PCA 去增益及时间关系共同判断。
- **右下邻域可信度**：仅衡量该尺度局部近邻保持，不是解释方差或 held-out 指标；抽样评价须保留 trial 身份，不以一个固定分数判合格。

## 图 4：TDR

### 计算公式
**符号**
- D：[1, cosθ, sinθ, z(g), z(τ)] 回归矩阵；β：逐通道最小二乘系数。
- Q：依 gain → time → cos → sin 顺序对系数向量 QR 正交化后的轴。
- ρ：held-out 方向平面角度与目标角的 Fisher–Lee 圆形相关；err：扣除整体偏移后的角误差。
- c_f = q_fold·q_full：折内轴与全队列参考轴的有符号余弦。
- vx、vy、speed：完整质量合格的 100 ms bin 在同一分析窗口内的平均速度分量及平均速率。
- effect_j = ||β_j||·SD(D_j)：统一到预测变量一个标准差变化的系数向量强度。

**步骤**
1. 按时间连续 block 做 CV，训练集排除测试 block 相邻 ±1 block；每折只用训练 trial 拟合神经标准化、回归和轴。训练集恒定通道不参与测试投影；零系数或依赖轴不当作有效轴展示。
2. 主图展示 held-out 方向平面、方向质心及 1 SD 椭圆；右侧展示角误差和完整重新拟合的 block 内置换零分布。无置换时 p 为未计算。
3. 角偏移由 pooled held-out 方向标签估计后扣除，所以角误差是描述性读出，并非无偏解码成绩；Fisher–Lee 相关不需要该偏移。
4. 以全队列轴作参考，绘制每折每个轴的 c_f。它描述轴稳定性，不是独立显著性检验。
5. 仅使用完整覆盖窗口、速度 bin 质量合格的共同 trial；至少 80 个 trial、3 个有效 block 时，分别拟合基础模型和加入 vx/vy/speed 的模型。两个模型的 trial、block 划分和评估集合相同；速度标准化只使用各折训练数据。
6. 比较两模型 held-out |ρ|，并展示全共同队列的 effect_j；所有预测变量强度、速度值和 trial 预测保存到表格。窗口不是完整 100 ms bin 倍数或样本不足时说明跳过原因，不改变窗口偷偷补齐。

### 结果解读
- **A held-out 方向平面**：查看未参与拟合的 trial 的方向排列及组内分散。
- **B 逐方向角误差**：比较各方向的偏差、离散及 ±45° 参考线。
- **C block 内置换**：比较观测绝对圆形相关和完整重拟合的零分布。
- **D 折间轴稳定性**：分轴读取训练折方向与全队列参考轴的有符号余弦。
- **E 同队列速度控制**：在相同有效 trial 和共同有效测试集合上比较加入 vx/vy/speed 前后的 held-out |ρ|。
- **F 条件预测变量效应**：比较系数向量范数乘预测变量 SD 后的方向、增益和时间效应。

### 质量评价标准
- **A held-out 方向平面**：与置换和折间稳定性共同评价；标签进入轴拟合，不能用样本内分离替代验证。
- **B 逐方向角误差**：整体偏移由 pooled 测试标签估计后去除，误差是描述性而非无偏解码成绩；不能要求所有方向完全一致。
- **C block 内置换**：p 的分辨率受置换次数限制；未置换、统计量无效时不作显著性结论，p 大不等于证明无信息。
- **D 折间轴稳定性**：接近 1 表示同向恢复，负值可能为不稳定/反向；全队列参考不是独立检验，近零或相关设计需谨慎。
- **E 同队列速度控制**：样本/覆盖不足时不计算；差异反映条件关联，不证明纯意图，在线 cursor 并非独立运动测量。
- **F 条件预测变量效应**：高共线性或秩亏会破坏唯一归因；效应大小不是解释方差，也不能作为因果贡献比例。

## 图 5：Supplementary PCA loadings and gain

### 计算公式
**符号**
- j* = argmax_i |corr(score_i, g)|，在请求计算的主成分范围内选择。
- loading：该 PC 的单位范数通道权重；F_in、F_cv：样本内和交叉验证得分的方向 ANOVA F。

**步骤**
1. 展示完整方差谱摘要、j* 得分与总发放率散点、各 PC 的 F_in/F_cv 和增益相关。
2. 将 j* 的 loading 映射到物理电极布局，不固定选择 PC1。
3. 虚线为理论 Bonferroni F 阈值，df=(7,n−8)；它不是主 PCA 图中的经验 max-F 置换阈值，也不是 block 相关性的校正。

### 结果解读
- **方差谱与累计轴**：读取前若干 PC 的方差及累计比例。
- **最强增益相关 PC 散点**：读取当前显示范围中 |corr| 最大的 PC 与总率关系。
- **方向 F 对照**：比较各 PC 的样本内与 CV F 及理论参考线。
- **各 PC 增益相关柱**：比较总率与每个成分的相关，查信号集中在哪些轴。
- **物理通道载荷图**：定位最强增益相关 PC 的正负通道权重及同号比例。

### 质量评价标准
- **方差谱与累计轴**：累计比例的分母是全部谱，不能将显示范围的总量重新归一成 100%。
- **最强增益相关 PC 散点**：这是数据选择后的描述，不能预设为 PC1，亦不能将相关称为原因。
- **方向 F 对照**：理论 Bonferroni 线不是 block 经验零分布；时间相关性、样本不平衡和轴交换影响解释。
- **各 PC 增益相关柱**：常数变量无有效 r；不要只关注最大一柱而忽略多个相关轴。
- **物理通道载荷图**：颜色为线性权重而非率，灰色缺失不是零；同号比例不能独立诊断全局伪迹。

## 图 6：Supplementary PCA held-out projections

### 计算公式
**符号**
- score_cv：训练折 PCA 投影得到的测试 trial 得分；PC1–PC3：按训练集方差排序的轴。

**步骤**
1. 上排展示全队列 PC1–PC2、PC2–PC3，下排展示相同编号的 held-out 投影。

3. 轴标签的解释方差来自全队列 PCA，并非测试解释方差；99.5 分位裁剪范围之外的点数会注明。

### 结果解读
- **上排 PC1–PC2 与 PC2–PC3**：分别读取全队列平面中的方向分布。
- **下排 PC1–PC2 与 PC2–PC3**：分别读取训练折标准化/拟合后对测试 trial 的投影。

### 质量评价标准
- **上排 PC1–PC2 与 PC2–PC3**：两图为不同轴组合，视觉分离不可直接解释为泛化；轴编号按方差而非方向信号排序。
- **下排 PC1–PC2 与 PC2–PC3**：符号对齐不能消除接近特征值导致的交换/旋转；标签中的方差比例来自全队列，不能当作测试解释率。

## 图 7：Supplementary TDR in-sample and readout

### 计算公式
**符号**
- in-sample：全队列拟合并投影本队列；held-out：训练折拟合后投影测试 trial。
- 方差占比 = 当前轴得分方差 / 相同评估样本标准化通道的总方差。

**步骤**
1. 并列展示 held-out 和样本内方向平面、各轴方差、目标与读出角、角误差直方图和置换零分布。
2. 方向平面与主 TDR 图来自同一拟合；质心连线和 1 SD 椭圆定义相同，不另选更好看的样本。
3. 目标与读出角的整体偏移由测试标签估计，误差仅作描述。置换次数沿用主分析参数。

### 结果解读
- **左上 held-out 平面**：读取独立测试投影的方向结构，与主 TDR 的 A 使用同一数据。
- **中上样本内平面**：查看同一批 trial 拟合和投影后的方向排列。
- **右上各轴方差**：比较 gain/time/cos/sin 捕获的标准化变异比例及 CV 版本。
- **左下目标与读出角**：看去整体偏移后的点是否沿目标附近排列。
- **中下角误差直方图**：读取中位绝对误差和 ±45° 内比例。

### 计算公式
**符号**
- 训练集均值 μ_c、群体总率均值 Ḡ、回归系数 β_c 均只用当前训练折估计。
- 测试残差 e_tc=x_tc−μ_c−β_c(G_t−Ḡ)，G_t 只对当前训练集选出的非恒定通道求和。
- μ_e、σ_e、V：训练残差均值、标准差和 PCA 载荷；测试坐标=[(e_test−μ_e)/σ_e]Vᵀ。

**步骤**
1. 沿用时间连续 block folds，训练排除测试 block 范围±1。每折在训练集选择非恒定通道，拟合截距与 β、选择非恒定残差通道、标准化、拟合 PCA。
2. 测试 trial 只计算自己的 total rate，使用训练集的全部参数变换并投影，不在测试数据上重算均值、β、SD 或 PCA。不使用方向标签拟合。

5. 导出逐测试 trial 的 fold/坐标、各训练通道的均值/β/残差缩放/载荷和 train/test 数量。维数不足时该折明确 unavailable；其余折仍保留。
