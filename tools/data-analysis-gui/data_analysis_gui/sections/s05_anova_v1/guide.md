# S05 · ANOVA

**一句话总结：**量化每个通道的方向均值差异、效应量及多重检验结果，并用空间分布和增益敏感性辅助解释。

本节回答：**哪些通道的分析窗口发放率随目标方向显著变化（方向调谐）？偏好方向如何分布？**
数据：Topbar 筛选后的方向队列；每个 trial、每个通道取 T_TRIAL_START + [窗口起点, 窗口终点)（默认 0.2–1.2 s）内的平均发放率
r = Σ计数 / (帧数 × 帧时长)（Hz）。窗口内无神经帧的 trial 剔除；「活跃通道」= 跨 trial 标准差 > 0。
可选「扣除全局增益」的 ANOVA 用来检查调谐是否只是全阵列一起变化。


阅读约定：以下按 subplot 的位置/标题逐项说明；重复的方向、电极、decoder 或记录面板逐个适用对应条目，双轴/色条与主面板合并解释。质量标准区分配置阈值、统计证据与描述性限制，历史数值不作为通用合格线。

## 图 1：ANOVA summary

### 计算公式
**符号**
- `t`：trial 编号，t = 1 … n；`n`：保留的 trial 数（1026 为 347，Grid 1028 为 367）。
- `c`：活跃通道编号，c = 1 … m；`m`：活跃通道数（跨 trial 标准差 > 0 的通道；1026 为 256，Grid 为 423）。
- `r(t,c)`：第 t 个 trial、第 c 个通道在分析窗口内的平均发放率（Hz）= 窗口内计数之和 ÷ (窗口内收到的帧数 × 帧时长 0.020 s)。分析窗口 = T_TRIAL_START + [窗口起点, 窗口终点)，默认 0.2–1.2 s；窗口内没有帧的 trial 被剔除。
- `d`：目标方向，0°、45° … 315° 共 8 个；`θ(t)`：第 t 个 trial 的目标方向角（弧度）；`n_d`：方向 d 的 trial 数。
- `k`：实际出现的方向数（通常 8）。
- `r̄_d(c)`：通道 c 在方向 d 上的平均发放率；`r̄(c)`：通道 c 在全部 trial 上的平均发放率（Hz）。
- `SS_between`：组间平方和（方向均值相对总均值的离散程度）；`SS_within`：组内平方和（同一方向内 trial 的离散程度）；`SS_total` = 两者之和。
- `F`：F 统计量；`df`：自由度 (k − 1, n − k)；`p`：F 分布给出的 p 值。
- `η²`：效应量（eta squared），0 到 1，方向能解释的方差比例。
- `q`：BH-FDR 校正后的 q 值；`α`：显著性水平（参数 alpha，默认 0.05）。BH = Benjamini–Hochberg 错误发现率控制。
- `total(t)`：第 t 个 trial 所有活跃通道 r(t,c) 之和（Hz）。
- `p_(i)`：活跃通道的 p 值从小到大排序后的第 i 个。
- 偏好方向：r̄_d(c) 最大的方向；调谐深度 = max_d r̄_d(c) − min_d r̄_d(c)（Hz）。
- 增益控制相关：`L(t,c)`：留一总发放率 = trial t 中除通道 c 以外所有活跃通道的 r 之和；`β(c)`：r 对 L 的回归斜率；`e(t,c)`：扣除增益后的残差。

**步骤**
1. 方向均值：r̄_d(c) = (Σ_{方向为 d 的 trial} r(t,c)) ÷ n_d；总均值 r̄(c) = (Σ_t r(t,c)) ÷ n。
   意思是：每个方向、以及全部 trial 的平均发放率。
2. 组间平方和：SS_between = Σ_d n_d · (r̄_d − r̄)²。
   意思是：不同方向的平均值彼此差多远。
3. 组内平方和：SS_within = Σ_t (r(t,c) − r̄_{d(t)})²，d(t) 是 trial t 的方向。
   意思是：同一方向内部 trial 之间有多散。
4. F 值：F = [SS_between ÷ (k − 1)] ÷ [SS_within ÷ (n − k)]，p = F 分布 (k − 1, n − k) 的右尾概率。
   意思是：方向间差异相对于方向内噪声有多大；无方向效应时 F ≈ 1。
5. 效应量：η² = SS_between ÷ SS_total。
   意思是：发放率的变化有多少比例可以归因于方向。
6. BH-FDR（只在 m 个活跃通道内做）：q_(i) = min_{j ≥ i} [p_(j) × m ÷ j]，上限 1；不活跃通道 q = 1。显著 = q < α。
   意思是：同时检验很多通道时，控制「显著结果中假阳性所占比例」不超过 α。
7. 总发放率检查：对 total(t) = Σ_c r(t,c) 做同样的单因素 ANOVA，显著时在注释里提醒。
   意思是：如果整体活动随方向变化，单通道「调谐」可能只是增益。
8. （勾选「扣除全局增益」时）留一总发放率：L(t,c) = Σ_{c' ≠ c} r(t,c')。
9. 回归斜率：β(c) = Σ_t (L − L̄)(r − r̄) ÷ Σ_t (L − L̄)²；残差 e(t,c) = (r − r̄) − β(c)·(L − L̄)。
   意思是：把通道活动中能被「其余通道总体高低」解释的部分去掉。
10. 对残差 e 重做第 1–6 步，但组内自由度再减 1（df = (k − 1, n − k − 1)，因为多估计了一个 β）。
    意思是：扣除增益后仍显著支持条件关联，但不证明纯粹方向机制。

### 结果解读
- **A F 分布**：看方向间差异相对于方向内变异的大小及显著通道位置。
- **B FDR 分布**：读取 −log10 q 与当前 α 的关系。
- **C 显著数量**：比较活跃、显著及可选增益控制后的数量和重叠。
- **D 偏好方向极坐标**：查看显著通道偏好方向计数。
- **E 效应量与均值**：比较 η² 与通道平均率，区分调制幅度和基线活动。
- **F 增益对照或调谐深度**：开启控制时比较原始与残差 F，否则比较 F 与方向峰谷差。

### 质量评价标准
- **A F 分布**：高 F 不是数据质量的单一标准，需核查有效样本和增益/时间混杂，独立性假设不由图保证。
- **B FDR 分布**：q<α 是当前检验族下的统计判据，不等于单通道结论为真的概率，也不是效果大小。
- **C 显著数量**：必须看分母与队列；增益控制前后数量变化不能直接判定哪个版本更好。
- **D 偏好方向极坐标**：不要求各方向均匀，集中偏好需核对方向样本量、任务设计和时间顺序。
- **E 效应量与均值**：低率下功效有限，较大 η² 仍需置信度/样本支撑；相关性不证明增益导致调谐。
- **F 增益对照或调谐深度**：控制保留仅支持条件关联而非纯方向机制；峰谷差大可能由离群值驱动，需看逐方向曲线。

## 图 2：ANOVA channel maps

### 计算公式
**符号**
- `F`、`q`、`η²`、`α`、偏好方向：与图 1 完全相同（每个活跃通道一组值）。
- `−log10 q`：q 取以 10 为底的负对数；q = 0.05 对应 1.3，q = 0.001 对应 3，数值越大越显著。
- 布局：物理工作簿布局（A–H 列、1–128 行）；没有布局文件时为 128 × 8 电极 ID 网格。

**步骤**
1. 左图数值：按参数「布局图数值」取 −log10 q（默认）、η² 或 F，只画活跃通道。
   意思是：颜色越深，该位置的方向调制越强/越显著。
2. 加框：q < α 的通道画方框（左图、中图）。
   意思是：一眼看出显著通道的空间分布。
3. 中图：η²；右图：只给显著通道涂上偏好方向的颜色，其余为灰。
   意思是：看显著通道偏好方向在阵列上是否成片。

### 结果解读
- **左侧可选显著性或效应图**：按所选 −log10 q、F 或 η² 的色条读取，方框标显著。
- **中间 η² 图**：定位方向均值差异所占的方差比例。
- **右侧偏好方向图**：只在显著通道中比较偏好方向的空间组织。

### 质量评价标准
- **左侧可选显著性或效应图**：不同量纲不能靠颜色比较；灰色代表未纳入/缺失，不是零效应。
- **中间 η² 图**：关注效应大小而非只看极小 q，空间聚集可能同时反映有效接触或共同噪声。
- **右侧偏好方向图**：邻近同色不是独立单元或神经拓扑的直接证据，需排除串扰、布局和选择偏差。

## 图 3：Top tuning curves

### 计算公式
**符号**
- `d`：目标方向，0°、45° … 315° 共 8 个；`θ(t)`：第 t 个 trial 的目标方向角（弧度）；`n_d`：方向 d 的 trial 数。
- `r̄_d(c)`：通道 c 在方向 d 上的平均窗口发放率（Hz），同图 1。
- `SEM_d(c)`：均值的标准误 = SD_d(c) ÷ √n_d，SD 用 ddof = 1（除以 n_d − 1）。
- `N`：画出的通道数（参数 top_n，默认 16）；`F`、`q`：同图 1。

**步骤**
1. 选通道：活跃通道按 F 从大到小排序，取前 N 个。
   意思是：展示方向调制最强的通道。
2. 每个方向画 r̄_d(c) 和误差棒 ± SEM_d(c)；0° 的值在 360° 处重复一次以闭合曲线。
   意思是：调谐曲线 = 发放率随方向的变化。
3. 点线 = 该通道全部 trial 的平均 r̄(c)。
   意思是：高于点线的方向是该通道「偏好」的方向。

### 结果解读
- **每个电极调谐子图**：按标题电极和 q/F，读取各方向均值、SEM、峰谷及总体均值线。

### 质量评价标准
- **每个电极调谐子图**：这些通道按同数据 F 选出，存在选择偏倚；误差相对峰谷小且样本充分较可信，单峰并非必要，双峰也不自动异常。

## 图 4：ANOVA tuning curves - all channels

### 计算公式
**符号**
- μ(d,c)、SEM(d,c)：通道 c 在方向 d 的分析窗口 trial 平均 Hz 和样本标准误；q(c)：本节普通方向 ANOVA 的 BH q。

**步骤**
1. 按实际电极 ID 递增分页，包含全部传输通道（包括不活跃通道），每页 8×8，最后一页空位隐藏。
2. 各子图画八方向 μ±SEM，虚线为全部 trial 等权总体均值；红色 * 表示本节普通 ANOVA q<alpha，蓝色未显著，灰色不活跃。
3. 每个子图独立设置 y 范围，并显示自己的 y 刻度；不共用最左列刻度。标题标物理电极 ID 和 q。
4. GUI 用 Prev/Next 或方向键翻页，支持缩放；每页可导出，另提供整组多页 PDF。

### 结果解读
- **每个电极调谐子图**：分别读取该通道的方向均值、SEM 和 Hz 刻度，比较峰谷及总体均值线；标题 * 表示方向显著。

### 质量评价标准
- **每个电极调谐子图**：不同子图 y 范围独立，不能按曲线视觉高度比较绝对幅度；结合 SEM、样本量与 q，不把非显著或低发放直接判为坏通道。

## 图 5：ANOVA tuning curves - significant channels

### 计算公式
**符号**
- S：本节普通方向 ANOVA active 家族中 q<alpha 的通道集合；μ、SEM、q 与全部通道分页图完全相同。

**步骤**
1. 仅从 S 取通道，按 q、原始 p、电极 ID 排序；不以可选 gain-controlled 显著性替换。
2. 每页 8×8，独立 y 范围、逐子图刻度、标题电极和 q，均值±SEM 与全部通道页一致。
3. 无显著通道时保留明确提示页；可通过 Prev/Next 翻页或打开整组 PDF。

### 结果解读
- **每个显著电极调谐子图**：检查入选方向差异的幅度、形状与误差；这是全部通道曲线的筛选版本。

### 质量评价标准
- **每个显著电极调谐子图**：使用同数据筛选存在选择偏差，极小 q 不等于大效应或可解码；读取各自 y 刻度，不假设所有图共用左列刻度。

## 注意事项
- ANOVA 只检验「8 个方向均值是否相同」，不假设余弦形状；方向在时间上的组织见 S06，群体层面的方向平面见 S04。
- 与 S01 共用同一份 ANOVA 结果（S01 自动选电极时的 F 最大通道就是本节的第一名）。
- 方向与 block/时间若不平衡（Grid 任务），方向效应可能与漂移混叠；可用 S04 的 TDR（含 time 轴）交叉检查。
- 显著性不等于解码可用性；解码性能见 S09。
