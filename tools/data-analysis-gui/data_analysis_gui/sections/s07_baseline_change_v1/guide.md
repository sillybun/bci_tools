# S07 · 方向/时间调谐汇总与基线响应变化

**一句话总结：**先汇总 S05 方向调谐、S06 时间响应及其重叠和配置层级组成，再用配对基线分析描述各方向响应变化。

本节回答：**在每个目标方向下，各通道在分析窗口里的发放比 trial 开始前高了还是低了、变化多少？各方向有多少通道显著变化？**
原有基线变化图的数据：Topbar 筛选后的方向队列；只保留响应窗口和基线窗口内**都有**神经帧的 trial（逐 trial 配对）。
响应窗口 = T_TRIAL_START + [窗口起点, 窗口终点)（Topbar，默认 0.2–1.2 s）；基线窗口 = T_TRIAL_START + [baseline_start, baseline_end)（本节参数，默认 −0.2–0 s）。
口径参考 macaque_data_analysis 的 `sdk/psth/direction_delta.py`。


阅读约定：以下按 subplot 的位置/标题逐项说明；重复的方向、电极、decoder 或记录面板逐个适用对应条目，双轴/色条与主面板合并解释。质量标准区分配置阈值、统计证据与描述性限制，历史数值不作为通用合格线。

前两张图继承当前 S05 / S06 参数并在同一记录上复用它们的统计函数；不要求先手动完成 S05 / S06，也不读取可能过期的图片或通道顺序。未设置来源参数时使用各自默认值。S05/S06 的参数、版本、代码以及当日 configs.ini 都进入结果签名，来源参数变化后会重新计算。
Direction-tuned 是 S05 普通 ANOVA 的 significant，不替换成可选 gain-controlled 结果；Time-tuned 是 S06 的事件后 bin 对基线时间响应检验，不是 S07 按方向的 Wilcoxon 检验。
**Active 分母**为 S05 的窗口率非恒定通道与 S06 的 binned 平均率大于 0 通道的并集，确保两类显著通道都包含在分母中；它可能不同于原基线变化图的 Active。两项来源保留各自有效 trial，图和表分别报告数量。
本节 baseline_start / baseline_end / test / alpha 仅控制原基线变化图；前两图分别使用 S05/S06 自己的 alpha、对齐、时间范围和基线设置。附件旧项目使用的统计方法不同，因此不强制复现附件数字。

## 图 1：Direction and time tuning overlap

### 计算公式
**符号**
- N：实际传输通道数，当前协议为 512；A5：S05 窗口率跨 trial 标准差>1e−12 的通道；A6：S06 全部 trial/bin 平均率>0 的通道；A=A5∪A6。
- D：A5 中普通方向 ANOVA 经 BH-FDR 校正 q<α5 的通道。
- T：A6 中 S06 逐事件后 bin 配对 t 检验，通道内 min-p×bin数 Bonferroni 后跨 A6 做 BH-FDR，q<α6 的通道。
- B=D∩T：Both-tuned；D-only=D\T，T-only=T\D；Active-not-significant=A\(D∪T)。

**步骤**
1. 使用本记录电极 ID 与存储列一一对应的来源统计，不按图上的排序或前 N 个通道求交集。
2. 左图分别画 N、|A|、|D|、|T|、|B|；D 与 T 都包含 B，因此不能把三者相加。
3. 中图分别计算 |D|/N、|T|/N、|B|/N；右图分别计算 |D|/|A|、|T|/|A|、|B|/|A|，以百分比标注。
4. 分母为 0 时标 N/A；任一来源检验不可用时显示具体原因，不把未计算归为 Inactive 或未显著。
5. 逐通道导出电极 ID、两个来源 active、两个 q 值、三个调谐标记及互斥类别，另导出来源设置与各分母。

### 结果解读
- **A 通道数量**：同时读取传输、Active、Direction、Time 和 Both 的数量；下方说明给出互斥类别及各来源 trial 数。
- **B 全部传输分母**：回答当前传输名额中，有多少比例达到各项检验标准。
- **C Active 分母**：回答至少被一项来源定义为活跃的通道中，有多少比例达到各项标准。

### 质量评价标准
- **A 通道数量**：Both 不得大于 D 或 T，显著通道必须属于并集 Active；不要求 D/T/Active 与附件或其他记录相等，不把“未显著”称为没有调谐。
- **B 全部传输分母**：各比例使用实际 N；这些重叠比例不应相加成 100%，传输范围外电极不得纳入。
- **C Active 分母**：必须报告 A5/A6 的定义及 α、窗口、对齐和有效 trial；与原 S07 Active 分母不同不一定是错误，需按导出标记核对。

## 图 2：Tuning composition by config tier

### 计算公式
**符号**
- G：当日 configs.ini 的 Good、Uncertain、Bad 或未在三个列表中的 Unlisted。
- N_G：实际传输且属于 G 的电极数，不是 ini 列表的全部长度。
- 互斥类别：Inactive=A 的补集；Active-not-significant；Direction-only；Time-only；Both。
- 重叠发生比例：|G∩M|/N_G，M 分别为 Inactive、Active、D、T、B。

**步骤**
1. ini 中零基索引转换为一基电极 ID，按实际传输 ID 分组；Unlisted 独立于 Bad，绝不从补齐数量推断 Filler。
2. 左图用五个互斥类别堆叠，每组柱高恰好等于 N_G，柱顶标总数。
3. 右图显示每个配置组中的 Inactive、Active、Direction、Time、Both 的数量和组内百分比；这些行存在包含关系，不可相加。
4. 无配置时跳过本图；文件无效或组间电极重复时记录原因，不随意优先归类；空组比例为 N/A。

### 结果解读
- **A 配置组互斥组成**：逐 Good/Uncertain/Bad/Unlisted 读取静默、活跃未显著、仅方向、仅时间及 Both；比较数量时同时看组大小。
- **B 配置组重叠比例**：逐列读取 Inactive/Active 与三类调谐的组内发生比例，和左侧互斥数量核对。

### 质量评价标准
- **A 配置组互斥组成**：所有组总数合计必须等于传输 N、每组五类合计为 N_G；Good 标签是先验配置，不保证更高调谐比例，Bad 中显著不是自动错误。
- **B 配置组重叠比例**：Active=Direction-only+Time-only+Both+Active-not-significant，D/T 都含 Both；无样本列不报告 0%，不按单次比例高低自动修改通道配置。

### 三种检验分别回答什么

| 检验 | trial 如何分组 | 比较对象 | 一个通道得到几个结果 |
| --- | --- | --- | --- |
| S05 方向 ANOVA | 按方向分组 | 分析窗口平均率的方向间差异 | 1 个方向 q |
| S06 pooled 时间响应 | 所有方向 trial 合并，每个 trial 保留自己的基线 | 每个事件后 bin 相对同一 trial 基线 | 1 个 pooled 时间 q |
| S07 方向内时间响应 | 分别取 0°、45°…315° 的 trial | 该方向内，每个事件后 bin 相对同一 trial 基线 | 最多 8 个方向内时间 q |

S06 不是先对方向均值等权求平均再检验，而是把有效 trial 放到同一个配对检验中；样本较多的方向贡献更多 trial。S07 每个方向单独检验，不能把一个 pooled 通道标记复制到八个方向。

两者都先对事件后 bin 的 min-p 做 Bonferroni。S06 再跨活跃通道做 BH；S07 再跨可检验的通道×方向对共同做 BH，并要求每方向至少 8 个基线有效 trial、每检验 bin 至少 8 个有效配对值。分组、样本量和校正家族都变了，所以 S06 显著不等于至少一个 S07 方向必然显著，反之亦然。S07 的可检验 active 也按方向计算，不强行套用 pooled active。

例如：各方向同一时刻都比基线增加，S06 可能显著而 S05 不显著；两个方向分别增加和减少，pooled 效应可能抵消，但方向内效应仍可检出；各方向都有较弱共同变化时，合并 trial 可能显著，而分开后因样本量下降/校正更严格都未显著。方向内时间响应检验不直接比较方向，因此所有方向都高亮也完全可能。若要证明“两个方向反应时间不同”，仍需方向×时间交互或独立 trial 的时间特征解码。

## 图 3：Direction-specific tuning counts

### 计算公式
**符号**
- PD(d)：S05 显著且唯一偏好方向为 d 的通道；T(d)：方向 d 内时间响应显著通道；D：S05 全局方向检验显著通道；图 C 深色=D∩T(d)，浅色=PD(d)∩T(d)。

**步骤**
偏好方向只在 S05 普通 ANOVA 显著的通道内确定：取分析窗口方向平均 Hz 的唯一最大值。数值并列（rtol=1e-7、atol=1e-10）不强行分配；缺失方向不参与最大值。每通道最多贡献一个偏好方向。ANOVA 显著表示至少部分方向均值不同，不表示偏好方向显著高于每一个其他方向，也不排除宽调谐或双峰调谐。

方向内 Time-tuned：沿用 S06 的对齐事件、基线、bin 和 alpha，将 trial 按方向分组。每方向至少 8 个基线有效 trial，每个可检验 bin/channel 至少 8 个有限配对值。逐事件后 bin 检验同一 trial 的 bin Hz 减 baseline Hz 是否偏离 0（双侧配对 t 检验）；通道内 min-p 乘全部事件后 bin 数，再把全部可检验的 channel×direction 对共同做 BH-FDR。q<alpha6 为时间响应，兴奋/抑制都包括。无可检验通道的方向显示 N/A。

图 C 深色为 S05 全局方向检验显著且在 d 内时间响应显著的通道，可在多个方向重复；浅色进一步要求偏好方向为 d，每通道最多贡献一次。S05 本身不是逐方向选择性检验。它与图 1 混合所有方向的 Both 不同；方向内样本量较小、校正家族不同，不能期待求和复现图 1。逐方向导出 trial 数、可检验通道数；逐 channel×direction 导出 q、偏好标记和描述性峰时。

### 结果解读
- **A 偏好方向数量**：查看窗口平均发放最高的方向分布；仅统计 S05 显著且唯一最大值通道。
- **B 方向内时间响应**：查看每个方向有多少通道存在事件后相对基线的显著变化；一个通道可在多个方向重复计数。
- **C 方向与时间响应交集**：深色读 S05 显著通道在每个方向的时间响应数；浅色读 A∩B，即该方向偏好与时间响应共同出现。

### 质量评价标准
- **A 偏好方向数量**：检查并列未分配数量和 trial 平衡；偏好并非逐方向两两差异显著，方向均匀也不是必需的合格标准。
- **B 方向内时间响应**：结合各方向样本量、可检验通道数、校正和窗口解释；N/A 不等于 0，未显著不等于无响应。本检验不证明方向间时间曲线不同。
- **C 方向与时间响应交集**：浅色不得超过 A、B 或深色，深色不得超过 B；全局 ANOVA 显著不表示对方向 d 有特异选择性。Both 不代表纯运动意图、交互显著或样本外可解码。

## 图 4：ANOVA and PSTH - significant channels

### 计算公式
**符号**
- D/qD：S05 普通方向 ANOVA 的显著标记/q；T/qT：S06 混合所有方向的时间响应标记/q；T(d)/q(d)：S07 在方向 d 内的时间响应标记/q。
- 通道集合 S=D∪T，按电极 ID 排序；每页 32 个通道（4×8），每通道左右两个独立 subplot。

**步骤**
1. 左侧沿用 S05 分析窗口的八方向均值 Hz±SEM，方向 ANOVA 显著且唯一最大值的方向标星并画竖虚线。星号表示描述性偏好，不是某方向对其他方向的两两显著比较。
2. 右侧按 S06 事件/基线/bin 设置，以基线有效 trial 分方向计算平均绝对 Hz PSTH；平滑仅用于显示，导出原始和显示 bin 均值。左侧 S05 与右侧 baseline-eligible trial 集可能不同，不能把两者差异全部归因于时间信息。
3. q(d)<S06 alpha 的方向曲线加粗实线；其余方向为淡色虚线。高亮使用图 3 的方向内检验，不使用 S06 pooled q 或左侧偏好方向来代替。
4. 标题 D+/D−、T+/T− 和 qD/qT 是两个来源的通道级检验；右侧 Time(d) 列出显著方向角度，none 表示已检验但没有显著方向，N/A 表示没有可检验方向。方向 trial 数与 q(d) 逐通道导出。
5. 每个轴独立设置 y 范围、显示自身 Hz 刻度；Prev/Next 翻页并支持整组 PDF。无入选通道时显示提示页。S07 方向内显著但 D/T 均未显著的通道不在此页集合内，完整结果保留在图 3 的通道×方向表。

### 结果解读
- **每个通道左侧 ANOVA**：读取均值方向结构、误差、D/qD；星号及其颜色定位唯一偏好方向。
- **每个通道右侧 PSTH**：读取各方向时间过程；加粗只说明该方向相对自身基线存在显著时间响应，T/qT 则是混合方向的通道结论。

### 质量评价标准
- **每个通道左侧 ANOVA**：ANOVA 显著只说明至少部分方向均值不同，不能把唯一最大值称为逐方向选择性显著；读取本图 Hz 刻度和 SEM。
- **每个通道右侧 PSTH**：高亮曲线不表示方向之间显著不同，所有方向都可同时加粗；未高亮可能为未显著或 trial 不足。须结合导出 q(d)、trial 数和校正家族，不以曲线视觉分离证明方向×时间交互。

## 图 5：Temporal response examples

### 计算公式
**符号**
- ΔHz：逐 trial 的 bin Hz 减同一 trial 基线 Hz；SEM：ΔHz 跨 trial 的标准误；peak：平均 |ΔHz| 最大 bin 的中心时间。

**步骤**
探索性选择三类真实通道：①两个方向内时间响应均显著，S05 窗口均值相差不超过较大绝对均值或 1 Hz 的 20%，绝对响应峰时相差至少 100 ms，按峰时差×两方向中较弱的 −log10(q)/(1+相对均值差)选最大者；②有方向内时间响应但 S05 不显著；③S05 显著并存在方向内时间响应。后两类选最小方向内 q 的未重复通道，展示最显著的至多两个方向；不保证第三类展示方向恰好是该通道偏好方向。
曲线使用基线有效 trial 的原始事件后 bin-baseline 均值 ± SEM（不平滑），峰时为最大绝对均值变化的 bin 中心。无合格实例明确显示缺失，绝不代入模拟数据。峰值选择和示例选择均使用同一数据，因此只能用于探索。

### 结果解读
- **左侧相近均值与不同峰时**：查看整体平均相近的方向是否呈现不同时间过程；这说明平均窗口可能丢失时间信息，不意味着已验证方向可分性。
- **中间时间响应且 ANOVA 未显著**：查看不满足方向均值检验的通道是否仍携带事件相关变化；不将未显著叫作方向无关。
- **右侧方向与时间共同出现**：结合 S05 整体方向差异与方向内时间响应，观察响应发生的时间与正负。

### 质量评价标准
- **左侧相近均值与不同峰时**：检查 SEM、bin 分辨率及重复试次；峰时差未经独立检验，不能只据此断言方向×时间交互。需后续交互检验或 held-out 时间特征解码。
- **中间时间响应且 ANOVA 未显著**：共同事件响应也可能来自感觉、运动、状态和漂移；仅说明时间检验与方向均值检验回答不同问题。
- **右侧方向与时间共同出现**：Both 提供互补描述，不等于独立神经机制或更好的数据；示例有选择偏差，需要在独立 trial 复现。

## 图 6：Channel x direction delta

### 计算公式
**符号**
- `t`：trial 编号；只保留响应窗口和基线窗口都有神经帧的 trial（1026：347 个，Grid：367 个）。
- `c`：通道编号；活跃通道 = 响应与基线发放率合并后标准差 > 0 的通道（1026：257 个，Grid：423 个）。
- `d`：目标方向，0°、45° … 315°；`n_d`：方向 d 的配对 trial 数。
- `resp(t,c)`：响应发放率 = T_TRIAL_START + [窗口起点, 窗口终点)（Topbar，默认 0.2–1.2 s）内的计数之和 ÷ (帧数 × 0.020 s)，Hz。
- `base(t,c)`：基线发放率 = T_TRIAL_START + [baseline_start, baseline_end)（默认 −0.2 到 0 s）内同样计算，Hz。
- `Δ(t,c)`：单个 trial 的响应变化（Hz）；`Δ̄(d,c)`：方向 d 上 Δ 的平均（Hz）。
- `s(x)`：有符号对数（signed-log）= sign(x) × log10(1 + |x| ÷ 1 Hz)；保留正负号，把大数压缩、小数拉开；s(1 Hz) ≈ 0.30，s(10 Hz) ≈ 1.04。
- `P99`：所有方向、所有活跃通道 |Δ̄| 的 99 百分位（线性图色标上下限）；`max|Δ̄|`：|Δ̄| 的最大值。

**步骤**
1. 单 trial 变化：Δ(t,c) = resp(t,c) − base(t,c)。
   意思是：同一个 trial 里，响应窗口比 trial 开始前高了多少（Hz）。
2. 方向平均：Δ̄(d,c) = (Σ_{方向为 d 的 trial} Δ(t,c)) ÷ n_d；不活跃和未传输通道记为 NaN（灰）。
   意思是：每个 trial 等权，得到通道 × 方向的平均变化。
3. 左图（线性）：颜色 = Δ̄，以 0 为中心，上下限 ±P99，超出部分饱和。
4. 右图（signed-log）：颜色 = s(Δ̄)，上下限 ±s(max|Δ̄|)；色条刻度仍标原始 ΔHz（0、±0.5、±1、±2、±5、±10、±20 …）。
   意思是：同一组数值换一种色标，让 1–2 Hz 的小变化也能看见。

### 结果解读
- **左侧线性 ΔHz**：逐通道逐方向读相对基线的有符号均值变化，关注绝对幅度。
- **右侧 signed-log Δ**：查看与左图相同变化的压缩表示，识别较小幅度结构。

### 质量评价标准
- **左侧线性 ΔHz**：全红/全蓝可能为非方向响应或基线差异，不能仅据颜色判好坏；灰色缺失不是无变化。
- **右侧 signed-log Δ**：颜色不再与 Hz 线性对应；零散小变化需配合检验和样本量，不能因放大后可见而认定可靠。

## 图 7：Eight-direction layout delta (linear)

### 计算公式
**符号**
- `t`：trial 编号；只保留响应窗口和基线窗口都有神经帧的 trial（1026：347 个，Grid：367 个）。
- `c`：通道编号；活跃通道 = 响应与基线发放率合并后标准差 > 0 的通道（1026：257 个，Grid：423 个）。
- `d`：目标方向，0°、45° … 315°；`n_d`：方向 d 的配对 trial 数。

## 图 9：Significant change per direction

### 计算公式
**符号**
- `t`：trial 编号；只保留响应窗口和基线窗口都有神经帧的 trial（1026：347 个，Grid：367 个）。
- `c`：通道编号；活跃通道 = 响应与基线发放率合并后标准差 > 0 的通道（1026：257 个，Grid：423 个）。
- `d`：目标方向，0°、45° … 315°；`n_d`：方向 d 的配对 trial 数。
- `resp(t,c)`：响应发放率 = T_TRIAL_START + [窗口起点, 窗口终点)（Topbar，默认 0.2–1.2 s）内的计数之和 ÷ (帧数 × 0.020 s)，Hz。
- `base(t,c)`：基线发放率 = T_TRIAL_START + [baseline_start, baseline_end)（默认 −0.2 到 0 s）内同样计算，Hz。
- `Δ(t,c)`：单个 trial 的响应变化（Hz）；`Δ̄(d,c)`：方向 d 上 Δ 的平均（Hz）。
- `W`：Wilcoxon 符号秩统计量；`p`：配对检验 p 值；`q`：方向内 BH-FDR 校正后的 q 值（BH = Benjamini–Hochberg，见 S05）；`α`：显著性水平（默认 0.05）。
- `P(t)`：第 t 个 trial 的群体平均变化 = 该 trial 所有活跃通道 Δ(t,c) 的平均（Hz）。
- `SEM`：标准误 = SD ÷ √n_d。
- `IQR`：四分位距（第 75 百分位 − 第 25 百分位）。

**步骤**
1. Δ(t,c)、Δ̄(d,c)：与图 3 第 1–2 步相同。
2. 配对检验（每个方向 d、每个活跃通道 c，用方向 d 的 trial）：
   - 默认 Wilcoxon：去掉 Δ = 0 的 trial，按 |Δ| 排秩，W = 正 Δ 的秩之和，用正态近似（含并列秩校正）得双侧 p；
   - 可选 t 检验：t = mean(Δ) ÷ [SD(Δ) ÷ √n_d]，自由度 n_d − 1。
   Δ 全为 0 或没有变化的通道 p = 1；trial 数 < 3 的方向不检验。
   意思是：这个方向下，响应是否系统性地高于或低于基线。
3. BH-FDR：每个方向内，在活跃通道上对 p 做 Benjamini–Hochberg 得 q；显著升高 = q < α 且 Δ̄ > 0，显著降低 = q < α 且 Δ̄ < 0。
4. (a) 百分比 = 显著升高（或降低）的通道数 ÷ 活跃通道数 × 100%。
5. (b) 群体变化：P(t) = mean_c Δ(t,c)；每个方向画 mean(P) ± SEM；若有负值，半径整体平移使最小值 ≥ 0，红色虚线圈 = 0 Hz。
   意思是：整个阵列平均起来，各方向比基线高多少。
6. (c) 箱线图：每个方向活跃通道 Δ̄(d,c) 的分布（箱 = IQR，中线 = 中位数，须 = 1.5 × IQR，不画离群点）。

### 结果解读
- **左侧显著升降比例**：比较各方向显著升/降通道数和活跃通道百分比，注意横轴样本量。
- **中间群体 Δ 极坐标**：查看平均变化的方向排列和 SEM，按标记零圈读取正负。
- **右侧通道 Δ 分布**：逐方向比较中位数、四分位和须线，区分共同增益与少数极值。

### 质量评价标准
- **左侧显著升降比例**：比例差可能来自检验功效，不能要求方向均匀；当前 q 阈值是统计判据而非响应越多越好。
- **中间群体 Δ 极坐标**：存在负值时半径会整体平移，不能把离原点距离直接当作 ΔHz；均值可抵消异号通道。
- **右侧通道 Δ 分布**：箱体偏移不证明原因，离群被隐藏不等于不存在，需结合 baseline、有效 trial 和原始变化表。

## 注意事项
- 图 3–3 是描述性的（颜色 = ΔHz，不代表显著性，也没有逐通道 z-score）；显著性只看图 6。
- 基线默认取 T_TRIAL_START 前 0.2 s，此时 cursor 可能仍处于上一 trial 的 ITI 状态；如需「cursor inactive」基线，请调整 baseline_start / baseline_end 并核对事件时序。
- 只用单一响应窗口的平均值；随时间的变化见 S06，方向调谐的单因素检验见 S05。
- Wilcoxon 使用正态近似（小样本、并列多时比精确检验略保守）；每方向 trial < 10 时结论不稳。
