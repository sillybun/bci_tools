# S09 · 方向解码 Overview + examples

**一句话总结：**通过时间 block 交叉验证和置换检验评估方向或 Grid 目标可读性，并定位时间、方向及通道数上的差异。

本节回答：**从分析窗口内的群体发放率，能否在没见过的 trial 上读出目标方向？读得多准、是否显著、需要多少通道？**
数据：Topbar 筛选后的方向队列（direction cohort）。每个 trial 的特征 = 分析窗口（默认 T_TRIAL_START + 0.2 到 + 1.2 s）内
512 个传输通道各自的平均发放率（Hz，计数 / 0.020 s 后对窗口内的帧求平均；可选 sqrt(Hz)）。窗口内没有神经帧的 trial 被剔除，
全程为常数的通道被丢弃（"active channels"）。所有数字都是 held-out（交叉验证中该 trial 所在的折没有参与训练）。


阅读约定：以下按 subplot 的位置/标题逐项说明；重复的方向、电极、decoder 或记录面板逐个适用对应条目，双轴/色条与主面板合并解释。质量标准区分配置阈值、统计证据与描述性限制，历史数值不作为通用合格线。

## 图 1：Direction decoding overview

### 计算公式
**符号**
- `t`：方向队列中的 trial 编号，t = 1 … n（n = 队列 trial 数）。
- `x_t`：第 t 个 trial 的特征向量，每一维是一个 active 通道在分析窗口（T_TRIAL_START + 0.2 到 + 1.2 s）内的平均发放率（Hz；勾选 sqrt 时为 √Hz）。
- `active 通道`：全程不是常数的通道（标准差 > 0），只有它们进入模型。
- `y_t`：第 t 个 trial 的真实方向类别，0 … 7 分别对应 0°、45° … 315°。
- `Y`：one-hot 标签矩阵，每行对应一个 trial、共 8 列；真实类别那一列为 1，其余为 0。
- `fold（折）`：把 block 按时间顺序切成 5 段连续的组，每段轮流当一次测试集，记为 f = 1 … 5。
- `purge`：训练时额外去掉与测试组 block 范围相差 ≤ 1 的 block，防止相邻 block 的慢漂移泄漏到测试集。
- `n_train`：某一折训练集的 trial 数。
- `μ_train`、`σ_train`：训练集中每个通道的均值和标准差（只用训练 trial 计算）。
- `z_t`：z-score 后的特征 = (x_t − μ_train) ÷ σ_train，逐通道计算。
- `Z`：训练集所有 z_t 叠成的矩阵（n_train 行）。
- `λ`：ridge 惩罚强度（参数「Ridge λ」，默认 1）；`I`：单位矩阵。
- `p̄`：训练集里各类别所占比例（8 个数，和为 1）。
- `B`：ridge 系数矩阵（通道数 × 8）。
- `s_t`：第 t 个 trial 的 8 个类别得分；`ŷ_t`：预测类别。
- `recall_d`（召回率）：真实方向为 d 的 trial 中被预测对的比例。
- `BA`（balanced accuracy，平衡准确率）：8 个方向 recall 的平均；机会水平 = 1/8 = 12.5%。
- `N[d, q]`：真实方向 d、预测方向 q 的 trial 数（混淆矩阵计数）。
- `n_perm`：置换次数（参数「置换次数」，默认 200）；`BA_null`：一次置换得到的 BA。
- `F_c`：通道 c 的单因素 ANOVA F 值（因素 = 方向），只用训练 trial 计算。
- `k`：通道数曲线中使用的通道个数，k = 1, 2, 4, 8 … 直到全部 active 通道。

**步骤**
1. 标准化：z_t = (x_t − μ_train) ÷ σ_train。
   意思是：每个通道按训练集的均值和波动幅度换算成「偏离平均几个标准差」，测试 trial 也用训练集的 μ、σ。
2. 拟合：B = (ZᵀZ + n_train·λ·I)⁻¹ · Zᵀ · (Y − p̄)。
   意思是：用最小二乘把特征映射到 one-hot 标签，λ 越大系数越被压小，惩罚随训练样本数一起放大。
3. 类别得分：s_t = z_t · B + p̄。
   意思是：每个测试 trial 得到 8 个分数，越高表示越像该方向。
4. 预测：ŷ_t = argmax(s_t)。
   意思是：取得分最高的方向作为预测。
5. 交叉验证：对 f = 1 … 5，在去掉测试组和 purge block 后的数据上做第 1–4 步，只预测测试组。
   意思是：每个 trial 恰好被一个「没见过它」的模型预测一次，所有数字都是 held-out。
6. 召回率：recall_d = #{ŷ_t = d 且 y_t = d} ÷ #{y_t = d}。
   意思是：方向 d 的 trial 里猜对了多少比例。
7. 平衡准确率：BA = (recall_0 + recall_1 + … + recall_7) ÷ 8。
   意思是：每个方向同等权重，trial 数不均衡也不会偏向多数方向。
8. 混淆矩阵（行归一化）：显示值 = N[d, q] ÷ Σ_q N[d, q] × 100%。
   意思是：每一行是「真实为 d 的 trial 被预测成各方向的百分比」，对角线就是 recall_d。
9. 置换零分布：在每个 block 内部随机打乱 y_t，重新做第 1–7 步得到 BA_null，重复 n_perm 次。
   意思是：保持每个 block 的方向组成，只破坏「神经活动 ↔ 方向」的对应，看纯靠运气能得到多高的 BA。
10. p 值：p = (1 + #{BA_null ≥ BA}) ÷ (1 + n_perm)。
    意思是：零分布中不比观测差的比例；p 最小为 1/(1 + n_perm)。
11. 每折准确率：只用第 f 折测试 trial 按第 6–7 步计算的 BA；横线 = 全部 trial 汇总的 BA。
12. 通道数曲线（F 排序）：每个训练折内计算 F_c，取 F 最大的 k 个通道做第 1–5 步，再对全部 held-out trial 算 BA。
    意思是：选通道只看训练数据，测试折不参与，没有信息泄漏。
13. 通道数曲线（随机）：每折随机抽 k 个 active 通道做第 1–5 步，重复 random_draws 次，画均值 ± 标准差。
14. 文本面板：accuracy = #{ŷ_t = y_t} ÷ n；within ±45° = 预测为真实方向或相邻方向的比例；mean |error| = 圆周上预测与真实方向相差的平均角度。

### 结果解读
- **左上方向混淆矩阵**：逐真实方向读取归一化预测分布，区分正确、相邻与对向混淆。
- **中上置换零分布**：比较观测 BA 与 block 内置换结果。
- **右上每折准确率**：结合各折 block 范围和 n 检查波动。
- **下方通道数曲线**：比较训练折内 ANOVA 排序与随机子集随通道数变化的表现。
- **右下记录与参数摘要**：核对队列、特征、λ、CV、BA、机会与误差指标。

### 质量评价标准
- **左上方向混淆矩阵**：对角线集中是有利证据但需结合每行样本与置换；不能只用总准确率掩盖方向偏差。
- **中上置换零分布**：未计算时不得称显著，最小 p=1/(次数+1)；理论 12.5% 只适用于此八分类，不能替代经验检验。
- **右上每折准确率**：波动可能来自样本、任务或漂移，不能仅凭超过固定百分点诊断失效。
- **下方通道数曲线**：所有选择须在训练折内；随机均值不必单调，挑选最好 k 会有选择偏倚，需独立验证。
- **右下记录与参数摘要**：指标只有在相同队列和定义下可比；在线方向标签可作目标分类，但不代表独立运动解码。

## 图 2：Direction decoding examples

### 计算公式
**符号**
- `j`：方向队列 trial 按时间先后的序号，j = 0 … n − 1。
- `y_j`、`ŷ_j`：第 j 个 trial 的真实方向和 held-out 预测方向（预测方法见图 1）。
- `e_j`：圆周上的方向误差（以 45° 为一步）= |((ŷ_j − y_j + 4) mod 8) − 4|，取值 0 … 4。
- `ok_j`：预测是否正确（正确 = 1，错误 = 0）。
- `W`：滚动窗口的 trial 数 = max(8, n ÷ 20)（向下取整）。
- `s_j`：第 j 个 trial 的 8 个 ridge 类别得分（见图 1 第 3 步）。
- `n_examples`：示例 trial 数（参数，默认 8）。

**步骤**
1. 上图颜色：e_j = 0 画绿点，e_j = 1 画黄点，e_j ≥ 2 画红点；空心圆画在 y_j，实心点画在 ŷ_j。
   意思是：绿 = 猜对，黄 = 偏到相邻方向，红 = 偏得更远；灰色竖线连接错误预测和真实方向，虚线是折边界。
2. 滚动准确率：acc_j = (以 j 为中心的 W 个 trial 中 ok = 1 的个数) ÷ W。
   意思是：用 numpy convolve（mode = same）做滑动平均，两端不足 W 个 trial 处按 0 补齐，所以两端偏低。
3. 示例 trial：在 0 … n − 1 中均匀取 n_examples 个序号，画出各自的 s_j（8 根柱），黑框标出 y_j。
   意思是：直接看模型对这个 trial「更倾向哪个方向」以及有多犹豫。

### 结果解读
- **上方逐 trial 预测**：按时间和真实方向读取正确/相邻/较远错误的聚集。
- **中间滚动准确率**：观察局部均值随 trial 变化，与八分类机会水平比较。
- **下排每个 trial 类别得分**：在每个示例中比较真实类别框与最高预测得分。

### 质量评价标准
- **上方逐 trial 预测**：局部错误需与试次数、接收质量和行为状态对照，不能由颜色聚集直接定位故障。
- **中间滚动准确率**：重叠窗口有强相关且边界受平滑影响，不是逐时段独立显著性检验。
- **下排每个 trial 类别得分**：Ridge 类别分数不是概率，不能以峰值高度当置信度；选出的示例不能代替全体 held-out 评价。

## 图 3：Grid target decoding

（仅 Grid 任务记录出现。Grid 的目标位于格点上且起点不固定，八方向混淆矩阵意义有限，因此改为解码目标位置。）

### 计算公式
**符号**
- `t`：方向队列 trial 编号，t = 1 … n。
- `x_t`、`z_t`、`Z`、`λ`、`n_train`、`fold`、`purge`：与图 1 相同（窗口平均发放率特征、训练折 z-score、ridge 惩罚、5 个时间连续 block 组、±1 block purge）。
- `g_t`：第 t 个 trial 的目标位置 (target_x, target_y)，任务坐标单位。
- `a_t`：第 t 个 trial 的起始 cursor 位置；`g_t − a_t`：这一次要走的位移（方向 + 距离）。
- `ḡ_train`：训练集目标位置的均值；`ĝ_t`：held-out 预测的目标位置。
- `W`：回归系数矩阵（通道数 × 2）。
- `SSE`：残差平方和 Σ(g − ĝ)²；`SST`：总平方和 Σ(g − ḡ)²，ḡ 为全部 trial 的均值；分别按 x、y 轴计算。
- `R²`：决定系数 = 1 − SSE ÷ SST；1 表示完全预测，0 表示与「总是猜均值」一样，负数表示更差。
- `‖·‖`：欧氏距离（两点之间的直线距离）。
- `K`：唯一目标的个数（目标坐标四舍五入到 0.001 后去重）；`c_t`：第 t 个 trial 的目标类别 1 … K。
- `BA`：K 个目标各自召回率的平均（召回率定义同图 1）；机会水平 = 1/K。
- `n_perm`：置换次数（与图 1 同一参数）。

**步骤**
1. 回归拟合：W = (ZᵀZ + n_train·λ·I)⁻¹ · Zᵀ · (g − ḡ_train)。
   意思是：用 ridge 把窗口发放率直接映射到目标的 (x, y) 坐标。
2. 预测：ĝ_t = z_t · W + ḡ_train，按 5 折 block CV（±1 purge）对每个 trial 预测一次。
3. 每轴 R²：R²_x = 1 − SSE_x ÷ SST_x，R²_y 同理。
   意思是：预测解释了目标 x（或 y）坐标变化的多少比例。
4. 合并 R²：R²_xy = 1 − (SSE_x + SSE_y) ÷ (SST_x + SST_y)。
5. 中位误差：median_t ‖ĝ_t − g_t‖；基线 = median_t ‖ḡ − g_t‖。
   意思是：一半 trial 的预测离真实目标比这个距离近；基线是「永远猜目标中心」时的误差。
6. 位移 R²：把第 1–4 步中的 g_t 换成 g_t − a_t 再算一遍。
   意思是：检验神经活动是否更直接地编码「往哪走、走多远」。
7. 目标身份分类：标签换成 c_t，用 K 列 one-hot 做图 1 的第 1–7 步，得到 BA，与 1/K 比较。
   仅当 K ≤ 64 且每个目标 ≥ 3 个 trial 时计算。
8. 置换 p 值：在每个 block 内打乱 c_t，p = (1 + #{BA_null ≥ BA}) ÷ (1 + n_perm)。
9. 作图：左图每个目标（空心方块）连到其 trial 的平均 ĝ_t（蓝点）；中间两图逐 trial 画 ĝ 对 g（x、y 各一张）；
   右图为 K × K 行归一化混淆矩阵，目标按 (x, y) 排序。

### 结果解读
- **左侧目标位置与预测质心**：比较目标与预测的空间位置、收缩及中位误差。
- **中间 x 坐标散点**：比较真实/预测 x 与对角线、R²。
- **中间 y 坐标散点**：单独检查 y 的误差和 R²，避免被 x 的较好表现掩盖。
- **右侧目标身份混淆矩阵**：逐目标看预测身份，结合 K、BA、1/K 和置换。

### 质量评价标准
- **左侧目标位置与预测质心**：回归收缩不自动异常，优于基线需同队列比较；不能只凭有序排列断言目标位置被准确编码。
- **中间 x 坐标散点**：正相关不排除比例或偏置错误，R²≤0 表示未优于对应均值基线。
- **中间 y 坐标散点**：与 x 的单位和范围相同才可直接比较；小方差时 R² 不稳定，须同时看误差。
- **右侧目标身份混淆矩阵**：类别很多且样本少时矩阵会稀疏，位置和位移预测与身份分类不是同一任务，不能从相对 R² 大小直接判定编码机制。

## 注意事项
- 解码只用分析窗口内的平均发放率，不含时间动态；连续运动的读出见 S10（速度解码）。
- ridge λ 与 sqrt 选项会改变绝对数值；跨天比较时请保持同一参数（见 X04）。
- 未经通道筛选的记录（10-26 / 10-27 传输电极 1..512）含大量静默或噪声通道，BA 天然偏低；通道筛选的影响见 S08 与 S12 面板 2。
- online 记录中 cursor 由解码器驱动，但目标方向由任务设定，因此方向解码仍然是有效的离线评估。
