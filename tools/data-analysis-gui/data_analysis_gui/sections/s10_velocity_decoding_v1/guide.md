# S10 · 速度解码 Overview + examples

**一句话总结：**在共同 held-out 时间 bin 上比较速度解码器的精度、方向差异、轨迹重建及计算代价，报告不确定性和适用范围。

本节回答：**能从神经活动多准确地逐 bin 解码出光标速度？不同 decoder 之间差多少？**
数据：Topbar 筛选后的**速度队列**（velocity cohort，方向队列再加速度 bin 质量标准，见注意事项）。每个 trial 从
T_TRIAL_START + 0.2 s 起切 10 个 100 ms bin（参数可改），所有数字都是 5 折时间顺序 block 交叉验证的 held-out 结果。
速度解码固定为 Ridge 和 Vel-KF，均为本地实现。

阅读约定：以下按 subplot 的位置/标题逐项说明；重复的方向、电极、decoder 或记录面板逐个适用对应条目，双轴/色条与主面板合并解释。质量标准区分配置阈值、统计证据与描述性限制，历史数值不作为通用合格线。

## 图 1：Velocity decoding overview

### 计算公式
**符号**
- `t`：trial 编号；`t₀`：第 t 个 trial 的 T_TRIAL_START 接收时间 + offset（默认 0.2 s），单位 s。
- `Δ`：评估 bin 宽度（参数 bin，默认 0.1 s）；`k`：bin 序号，0 … K−1（K = n_bins，默认 10）；第 k 个 bin 覆盖 [t₀ + k·Δ, t₀ + (k+1)·Δ)。
- `p(τ)`：时刻 τ 的 cursor 位置（x, y，任务坐标单位），由同一 trial、active 状态下相邻两个 cursor 采样线性插值得到；两采样间隔必须 ≤ velocity_cursor_gap（默认 0.1 s）。
- `v_k`：第 k 个 bin 的真实（GT）cursor 速度，二维（v_x, v_y），单位任务坐标单位/s。
- `c_{f,e}`：第 f 帧神经数据在电极 e 上的计数（0–3，3 表示 ≥3）；每帧积分 0.020 s。
- `W_n`：尾随神经窗口长度（velocity_neural_window，默认 0.2 s），截止于 bin 右端。
- `N_k`：第 k 个 bin 的尾随窗口内收到的帧数（必须 ≥ velocity_min_frames，默认 4；窗口内含边界的最大接收空档 ≤ velocity_max_gap，默认 0.15 s）。
- `x_k`：第 k 个 bin 的特征向量，每个传输电极一个值，单位 Hz。
- `block`：任务中的一个 block（连续的一组 trial）；`fold`：交叉验证的一折，共 5 折。
- `train` / `test`：某一折的训练集与测试集；held-out = 用没见过该 bin 的模型做出的预测。
- `μ`、`σ`：训练集每个电极特征的均值与标准差（只用训练行；训练中 σ ≈ 0 的电极去掉）。
- `z_k`：标准化后的特征，z_k = (x_k − μ) / σ（逐电极相除）。
- `W`、`v̄_train`（Ridge）：权重矩阵（电极数 × 2）与训练集平均速度；`λ`：正则强度（lam_ridge，默认 1），`n`：训练 bin 数，`I`：单位矩阵。
- `s_k`（Velocity KF）：第 k 步的状态 = 速度 ÷ 训练 RMS 速度；`A`：2×2 状态转移矩阵；`Wp`：状态噪声协方差；`C`：观测矩阵（电极数 × 2）；`b`：观测偏置；
  `Q`：观测噪声协方差（电极数 × 电极数）；`α`：Q 向对角收缩的比例（q_shrinkage，默认 0.5）；`P`：状态估计的不确定度（协方差）；`K`：卡尔曼增益；`λ_kf`：最小二乘正则（lam_kf，默认 1e-4）。
- `v̂_k`：decoder 对第 k 个 bin 的 held-out 速度预测；`v̄`：测试 bin 上真实速度的均值（按轴）。
- `SSE`：误差平方和，Σ_k (v_k − v̂_k)²（按轴）；`SST`：总平方和，Σ_k (v_k − v̄)²（按轴）。
- `R²`：决定系数，= 1 − SSE/SST；1 表示完全预测，0 表示等于直接猜均值，负数表示比猜均值还差。
- `RMSE`：均方根误差，sqrt(SSE / n)，n 为 bin 数，单位任务坐标单位/s。
- `r`：Pearson 相关系数（−1 … 1），只看线性相关、不看幅度。
- `共同 bin`：所有所选 decoder 都有预测的测试 bin，指标只在这些 bin 上算。
- `block bootstrap`：把测试 bin 按 block 分组，有放回地整块重抽同样多个 block，重复 B 次（n_boot，默认 200）。
- `CI`：95% 置信区间，= B 次重抽得到的 mean R² 的第 2.5 与第 97.5 百分位数。

**步骤**
1. 真实速度：v_k = (p(t₀ + (k+1)·Δ) − p(t₀ + k·Δ)) ÷ Δ。
   意思是：bin 右端位置减左端位置，再除以 bin 宽。
2. 神经特征：x_{k,e} = (Σ_{窗口内的帧 f} c_{f,e}) ÷ (N_k × 0.020 s)。
   意思是：截至 bin 右端的 W_n 秒里，电极 e 每秒平均发放几次。
3. 交叉验证：block 按时间先后分成 5 组；每折测试一组，训练集去掉与测试组相邻（±1）的 block。
   意思是：用别的时间段训练、预测这一段，并留出缓冲避免相邻 block 互相泄漏。
4. 标准化：z_k = (x_k − μ) ÷ σ，μ、σ 只来自训练集。
   意思是：每个电极变成「比训练时平均高几个标准差」。
5. Ridge：v̂_k = z_k · W + v̄_train，其中 W = (ZᵀZ + n·λ·I)⁻¹ · Zᵀ(V − v̄_train)（Z、V 为训练集所有 z_k、v_k 叠成的矩阵）。
   意思是：线性回归，λ 越大权重越小、越不容易过拟合。
6. Velocity KF 模型：s_k = A·s_{k−1} + 噪声(Wp)；z_k = C·s_k + b + 噪声(Q)；A、C、b 由训练集最小二乘（正则 λ_kf）估计。
   意思是：速度会延续上一步，神经活动是速度的线性函数加噪声。
7. Q 收缩：Q ← (1 − α)·Q + α·diag(Q)。
   意思是：把电极之间的噪声相关性打一半折扣，减少用几千个 bin 估计 512×512 矩阵时的过拟合。
8. KF 预测步：s⁻ = A·ŝ_{k−1}，P⁻ = A·P_{k−1}·Aᵀ + Wp。
   意思是：先按上一步速度猜这一步，并放大不确定度。
9. KF 更新步：K = P⁻·Cᵀ·(C·P⁻·Cᵀ + Q)⁻¹，ŝ_k = s⁻ + K·(z_k − C·s⁻ − b)，P_k = (I − K·C)·P⁻；v̂_k = ŝ_k × 训练 RMS 速度。
   意思是：用这一步实际看到的神经活动修正猜测；每个连续序列（trial 开头或断档后）开头状态清零。
13. 20 ms → 100 ms：v̂_k(100 ms) = (该 bin 内 5 个 20 ms 预测之和) ÷ 5，5 个都有才算。
    意思是：速度是位移/时间，5 个 20 ms 真实速度的平均正好等于 100 ms 的真实速度，所以可直接与 v_k 比较。
14. 指标只在共同 bin 上算：每轴 R² = 1 − SSE/SST，mean R² = (R²_x + R²_y) ÷ 2。
   意思是：所有 decoder 用同一批 bin 比较。
15. RMSE = sqrt(SSE ÷ n)（每轴）；Pearson r 每轴单独算。
    意思是：RMSE 是典型误差的大小，r 只看预测与真实是否同涨同落。
16. 误差棒：block bootstrap B 次，每次算一次 mean R²，取 2.5% 与 97.5% 分位数作为 CI。
   意思是：整块重抽保留了块内 bin 的相关性，CI 不会被低估。
17. 下排二维直方图：横轴 v_k、纵轴 v̂_k，60×60 格，范围 ±1.1 × |v| 的 99.5 分位数，颜色为对数计数；斜线为 v̂ = v。
    意思是：点越集中在斜线附近，预测越准；颜色越深表示该处 bin 越多。

### 结果解读
- **左上 R² 与区间**：比较各 decoder 的 x/y 及平均 R²，按图例读取 block-bootstrap 区间。
- **中上 RMSE**：分别比较 x/y 的速度误差。
- **右上 Pearson r**：比较各轴时间协变的一致程度。
- **每折 R²**：逐相同时间折检查所有模型的好坏和一致性。
- **各 decoder 的 vx/vy 散点**：每个面板比较预测与 GT 的相应分量及对角线。

### 质量评价标准
- **左上 R² 与区间**：R²≤0 表示未优于对应均值基线；区间重叠不等于无差异，平均 x/y 与 pooled R² 不是同一指标。
- **中上 RMSE**：越小表示该单位下误差较低，但需对照速度尺度；跨记录运动幅度不同不能只比绝对 RMSE。
- **右上 Pearson r**：r 高不保证增益和偏移正确，必须与 R²、RMSE 联读。
- **每折 R²**：局部负值需检查样本及状态，不以固定折间差异作质量判决。
- **各 decoder 的 vx/vy 散点**：关注偏置、尺度、饱和和异方差；同一共同测试集合才能公平比较，在线 GT 是闭环 cursor。

## 图 2：Velocity traces (examples)

### 计算公式
**符号**
- `t`：被选作示例的 trial，按时间均匀取 n_examples 个（默认 6）。
- `k`：bin 序号；`Δ`：bin 宽（默认 0.1 s）；offset：首个 bin 相对 T_TRIAL_START 的起点（默认 0.2 s）。
- `v_k`：第 k 个 bin 的真实 cursor 速度（任务坐标单位/s），= (bin 右端位置 − 左端位置) ÷ Δ。
- `v̂_k`：各 decoder 的 held-out 预测（与图 1 相同的 5 折 block 交叉验证）。

**步骤**
1. 横坐标：bin 右端时刻 = offset + (k + 1) × Δ（相对 T_TRIAL_START）。
   意思是：每个点画在该 bin 结束的时刻。
2. 纵坐标：分别画 v_k 与每个 decoder 的 v̂_k（x、y 各一小图）；某 decoder 没有预测的 bin 留空。
   意思是：与图 1 的数字完全相同，只是按 trial 展开看时间过程。

### 结果解读
- **每个示例的 vx 面板**：对照当前 trial 的 GT 与所有模型横向分量，检查起点、峰值、延迟和反向误差。
- **每个示例的 vy 面板**：独立读取纵向峰谷、停顿及模型差异。

### 质量评价标准
- **每个示例的 vx 面板**：示例仅作形态检查，不以局部吻合替代 held-out 总指标；缺 bin 不应连线掩盖。
- **每个示例的 vy 面板**：与 vx 同时评价，相关高但尺度错仍有运动误差；不同 trial 之间不应当作连续预测。

## 图 3：Integrated trajectories by direction

### 计算公式
**符号**
- `p̂_k`：积分得到的第 k 个 bin 左端位置（任务坐标单位）；`p̂_0` = bin 0 左端的真实 cursor 位置。
- `v̂_k`：decoder 的 held-out 速度；GT 轨迹用真实速度 v_k 代替 v̂_k。`Δ`：bin 宽（0.1 s）。
- `L`：该方向所有可用 trial 中最短的点数；`d`：目标方向（0°…315°）。
- `v̄_d`：方向 d 的测试 bin 上真实速度的均值；`SSE_d`、`SST_d`：方向 d 内 x、y 合并的误差平方和与总平方和。
- `R²_d`：方向 d 内的决定系数；`RMSE_d`：方向 d 内速度向量误差的均方根（任务坐标单位/s）。

**步骤**
1. 积分：p̂_{k+1} = p̂_k + v̂_k × Δ。
   意思是：从真实起点出发，按解码速度一步步走。只用 bin 连续、从 bin 0 开始、且该 decoder 全部有预测的 trial。
2. 粗线：方向 d 的平均轨迹 = 各 trial 前 L 个点的逐点平均；细线最多画 40 个 trial。
   意思是：粗线代表该方向的典型轨迹，细线显示 trial 之间的差异。
3. 分方向 R²：R²_d = 1 − SSE_d ÷ SST_d，SSE_d = Σ‖v_k − v̂_k‖²，SST_d = Σ‖v_k − v̄_d‖²（只在方向 d 的共同 bin 上）。
   意思是：去掉方向之间的差异，只看方向内部随时间的变化能否被解码，所以比总体 R² 低。
4. RMSE_d = sqrt(mean ‖v_k − v̂_k‖²)。
   意思是：该方向典型的速度误差大小。

### 结果解读
- **GT 轨迹面板**：查看真实 bin 速度从规定起点积分后的方向轨迹。
- **各 decoder 轨迹面板**：在相同起点和积分范围内比较每个方向的形状、终点和漂移。
- **各方向 R²**：比较各模型在方向内速度变化上的解释。
- **各方向 RMSE**：检查是否某方向/模型的速度误差突出。

### 质量评价标准
- **GT 轨迹面板**：这是同一速度窗口的积分，不一定覆盖完整任务轨迹，不能与原始完整 cursor 路径混为一谈。
- **各 decoder 轨迹面板**：速度小偏置会累积成大位置误差；较漂亮的平均轨迹可能掩盖 trial 误差，断 bin trial 不可直接积分比较。
- **各方向 R²**：方向内方差通常更小，分数可能明显低于 pooled R²；不把负值一概归为没有任何方向信息。
- **各方向 RMSE**：需对照该方向速度尺度与 bin 数，没有适用全部记录的统一误差阈值。

## 图 4：Decoder comparison

### 计算公式
**符号**
- `共同 bin`：所有所选 decoder 都有预测的测试 bin；`mean R²`：(R²_x + R²_y) ÷ 2，R² = 1 − SSE/SST（见图 1）。
- `RMSE`：每轴均方根误差（任务坐标单位/s）。
- `CV 耗时`：某 decoder 5 折交叉验证的拟合 + 预测总时间（s）。
- `fold`：交叉验证的一折（共 5 折，按时间顺序的 block 分组）。
- `block bootstrap`：按 block 整块有放回重抽测试 bin；`B`：重抽次数（n_boot，默认 200）。
- `best`：mean R² 点估计最高的 decoder。
- `ΔR²`：某 decoder 的 mean R² 减去 best 的 mean R²（负数 = 比 best 差）。
- `配对 CI`：每次重抽用同一批 block 给所有 decoder 打分后再相减，得到 B 个 ΔR²，取 2.5% 与 97.5% 分位数。
- `R²_d`：方向 d 内的 R²（x、y 合并，SST 以方向自身均值为中心，同图 3）。

**步骤**
1. (a)(b)：在共同 bin 上算每轴 R²、mean R²、每轴 RMSE；误差棒为 block bootstrap 的 95% CI。
   意思是：与图 1 相同的指标，所有 decoder 放在一张图上对比。
2. (c)：每个 decoder 的 CV 耗时，对数横轴。
   意思是：对数轴上相差一格就是快慢差 10 倍。
3. (d)：每折单独算 mean R²，灰线连接同一折在不同 decoder 上的值。
   意思是：看 decoder 的排序是否每折都一样。
4. (e)：第 b 次重抽得到 R²_m(b) 与 R²_best(b)，ΔR²(b) = R²_m(b) − R²_best(b)；CI = ΔR²(b) 的 2.5% 与 97.5% 分位数；柱高 = 点估计之差。
   意思是：同一批 block 上比较，两者共同的数据波动被抵消，比看两个独立 CI 是否重叠更灵敏。
5. (f)：R²_d = 1 − SSE_d ÷ SST_d，行 = decoder，列 = 方向；< 0 显示为深紫色。
   意思是：一眼看出哪个方向、哪个 decoder 弱。
6. (g, h)：一个示例 trial 的 v_x、v_y，GT 与所有 decoder 叠加。只选一个 decoder 时仍出图，标题注明，(e) 显示无法比较。
   意思是：同一个 trial 上直接比较各 decoder 的曲线形状。

### 结果解读
- **A R² 与区间**：读取 x/y 和平均 R² 及其 block-bootstrap 不确定性。
- **B 分轴 RMSE**：独立比较两个运动分量的误差。
- **C CV 计算时间**：读取完成相同折数 CV 的墙钟耗时，注意对数轴。
- **D 配对每折结果**：沿同折连线比较 decoder，检查优势是否一致。
- **E 相对最佳模型差异**：看配对 block-bootstrap 的 ΔR² 与零线。
- **F 各方向 R² 热图**：逐方向逐模型识别弱点和负值。
- **G 示例 vx**：在同一 trial 内比较所有模型横向速度形态。
- **H 示例 vy**：对相同 trial 的纵向速度做独立检查。

### 质量评价标准
- **A R² 与区间**：比较必须同测试 bin，未计算 bootstrap 时不应声称有区间支持。
- **B 分轴 RMSE**：不用较好的一个轴代表整体；指标带任务单位，跨数据集须统一尺度。
- **C CV 计算时间**：时间依赖硬件、首次编译及实现，不代表纯推理时延或固定部署预算。
- **D 配对每折结果**：折非独立抽样，单折好坏不构成显著性结论。
- **E 相对最佳模型差异**：最佳模型在同一数据上选出，比较存在选择效应；区间跨零不支持明确优越，不能用 p_delta 当通用显著性 p。
- **F 各方向 R² 热图**：按色条与实际数字判断，低方向内方差会压低 R²；样本不平衡要同时核查。
- **G 示例 vx**：示例可解释误差但不代表总体水平，也不验证泛化到新记录。
- **H 示例 vy**：与 G 和总体指标联读，不能挑选单轴吻合来评价整个 decoder。

## 注意事项
- 速度队列规则来自 Topbar 的 TrialFilter：velocity_bin_policy = drop_trial 时，评估范围内任何一个 bin 不合格就去掉整个 trial；drop_bin 只去掉坏 bin。
  20 ms 原生 bin 使用相同的 cursor 空档、最大空档和 policy，只是神经窗口用 native_window（默认 0.2 s），最少帧数不超过窗口能容纳的帧数。
- R² 依赖速度方差：速度范围小的记录 R² 天然偏低，跨记录比较时同时看 RMSE 与 RMS 速度。
