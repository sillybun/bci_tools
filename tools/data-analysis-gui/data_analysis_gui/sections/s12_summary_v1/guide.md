# S12 · 单日分析一图流

**一句话总结：**汇总任务成功率、通道饱和分区、传输状态、降维概览与互斥通道组成。解码单独放在补充页。

## 图 1：Overview

### 计算公式
**符号**
- 成功率 = 成功次数 ÷ 有明确成功或失败结局的完整尝试数。
- p3 = 所选范围内码 3 帧占比，码 3 表示至少 3 次事件。
- D 和 T 分别为 S05 方向与 S06 时间检验显著的电极集合，Both = D ∩ T。

**步骤**
1. S01 用最近至多 40 次完整且结局明确的尝试画总体成功率。各方向曲线只取同一窗口内对应方向的尝试。
2. S02 采用当前范围、饱和分区阈值、通道配置及布局。S03 使用当前接收缺口阈值及汇总时间窗，采集缺帧由独立 FPGA 时钟估计。
3. S04 复用完整的两行三列概览。上行是原始 PCA、方向着色 UMAP 和 held-out TDR。下行是残差 PCA、block 着色 UMAP 和角度误差。
4. S07 A 把每个传输通道唯一归入 Inactive、Active not significant、Direction only、Time only 或 Both。有有效配置时按 Good / Uncertain / Bad / Unlisted 分柱，无有效配置时汇总为全体传输通道一柱。

### 结果解读
- **S01 任务成功率**：沿记录时间观察总体及各方向的成功率变化。
- **S02 电极布局**：查找饱和分区、零计数和帧内事件扎堆的空间分布。
- **S02 饱和度散点与组成**：对照平均观测发放率、码 3 占比和 Poisson 参考曲线，再读各分区通道数。
- **S03 时间线 A–C**：依次观察长接收间隔、独立时钟推断的缺帧事件以及两者按时间汇总的比例。
- **S03 分布与时钟映射 D–F**：分别查看接收间隔、FPGA 步长、主机与采集时间的映射及局部帧放大。
- **S04 PCA 列**：结合轴上的方差占比，对比去除总发放率线性关系前后方向结构。
- **S04 UMAP 列**：对照同一嵌入中的方向与 block 着色。
- **S04 TDR 列**：查看测试 trial 的方向平面和角度误差。
- **S07 互斥通道组成**：按柱读取五类通道数和各配置组总数。

### 质量评价标准
- **S01 任务成功率**：各方向曲线样本累积速度可能不同，早期波动要结合尝试数。
- **S02 电极布局**：未传输电极与有传输但零事件的电极需区分。
- **S02 饱和度散点与组成**：高码 3 占比提示计数截断，结合 Poisson 参考与阈值判断超预期扎堆。
- **S03 时间线 A–C**：长接收间隔和采集缺帧分别解释，缺少独立时钟时缺帧未知。
- **S03 分布与时钟映射 D–F**：核对直方图范围以外的间隔、异常时钟步长与局部缺口。
- **S04 PCA 列**：原始与残差 PCA 的方差分母各自独立，样本内分离用于描述。
- **S04 UMAP 列**：方向或 block 的局部聚集用于探索，坐标无物理单位。
- **S04 TDR 列**：结合来源页的置换、折间稳定性和运动学控制解读，误差展示使用标签估计整体旋转。
- **S07 互斥通道组成**：五类相加等于每柱总数，未通过显著性阈值的通道要结合试验功效判断。

## 图 2：Supplementary decoding overview

### 计算公式
**符号**
- BA：各方向或目标类别的召回率均值。R²、RMSE：预测相对真值的拟合与误差指标。

**步骤**
1. 按时间 block 留出测试样本，分别评估方向或 Grid 目标解码和速度解码。
2. 在线记录在同一评价时间窗对比闭环输出、离线预测和 cursor 速度。

### 结果解读
- **方向或目标**：读 held-out 混淆、置换分布或 Grid 位置与位移结果。
- **速度**：读各模型的速度指标和连续 trial 积分轨迹。
- **在线扩展**：比较在线与离线的速度指标及同一时间轴上的波形。

### 质量评价标准
- **方向或目标**：结合类别数、测试样本数与置换设置。
- **速度**：同时看 R²、RMSE 与轨迹偏差，按同一评价队列比较。
- **在线扩展**：cursor 由在线输出驱动，两者一致性属于闭环表现。

## 图 3：Supplementary channel-subset decoding impact

### 计算公式
**符号**
- G：configs.ini 的 good、good+uncertain、all、bad 子集；无配置时为明确标注的全部、≥1 Hz、码 3 占比≤1% 替代子集。
- BA：方向 balanced accuracy；Grid 用目标位置 R²；速度指标为 Ridge 的 x/y 平均 R²。

**步骤**
1. 保留旧版 S12 的通道子集解码影响计算，按当日配置与实际传输电极交集取列；不跨日期借用配置。
2. 每个子集在相同 block 划分中独立拟合方向/目标模型及 Ridge 速度模型，画子集通道数与结果。
3. 该图作为补充，不把同数据最优子集自动当作推荐；全部数值另行导出。

### 结果解读
- **子集数量与解码曲线**：同时读取所用通道数、方向或目标指标，以及速度 Ridge 指标。

### 质量评价标准
- **子集数量与解码曲线**：子集大小和分母可能不同，双轴量纲不能混同，替代组不是配置质量评级；同数据选择最优子集存在选择偏差。
