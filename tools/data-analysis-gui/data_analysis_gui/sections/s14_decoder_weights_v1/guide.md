# S14 · 解码权重与电极深度

**一句话总结：**六张 hot_r 0–25 权重图沿用 S10 拟合；新增第七张图按整段录制的非零 code 通道统计深度分布。

S14 独立选择 Ridge（默认）或 Velocity KF，自动继承 S10 的 bin、offset、until、sqrt 和模型训练参数。所有图默认下方 Elec# 0、上方 127，Shank 从左到右 1–8。文件名不加方向后缀。全量拟合用于描述模型敏感度，不是 held-out 性能评价。默认 per_SD：输入变化一个拟合标准差的敏感度；per_feature_unit：再除以拟合输入标准差，单位为每 Hz 或每 sqrt(Hz)。跨 run 应保持模型、参数、输入变换和权重单位一致。

Ridge 取标准化特征的系数。KF 取稳态神经输入增益 K 乘训练速度尺度，不使用观测矩阵 C 充当解码权重。KF 协方差从 P=0 迭代至增益相对变化 ≤1e-10；实际 trial 初始阶段的瞬态增益不在固定图中。

图和 CSV 的 vx、vy 均为绝对值。原始带符号系数另存 vx_signed、vy_signed。norm = sqrt(wx² + wy²)，取绝对值不改变 norm。灰色仅表示未传输；输入恒定而被剔除的通道权重为零，显示白色。其他非常数通道也可能有零或很小的权重，不能把白色统称为没有信息。

Channel# 为 XDF 电极 ID 减一。Shank 为 1–8，Electrode # 为工作簿位点编号 1–128。Elec# 是位置序号，没有植入方向与毫米深度标定时不能推断脑内解剖深度。

## 图 1：vx weighting heatmap

### 计算公式
**符号**
- wx：模型对应 vx 的原始带符号权重。显示值 a = |wx|。
**步骤**
1. 以当前 run 的 S10 参数拟合模型，提取 wx，并逐位点取绝对值。
2. 按新 mapping 放入 Shank / Elec# 网格，统一用 hot_r、0–25 色条。
3. 大于 25 的值使用色条顶端颜色，色条上端三角表示超范围；不改变原始权重数值。

### 结果解读
- **权重热力图**：白色为零，黄色、红色至黑色表示逐渐增大的幅度，灰色为未传输。
- **固定色条**：所有 run 使用相同权重值到颜色的对应关系。

### 质量评价标准
- **权重热力图**：绝对值不保留正负方向；权重敏感度不等于独立解码贡献。
- **固定色条**：顶端颜色可能表示 25 或更高的数值，需用数值图或 CSV 区分。

## 图 2：vx weighting values

### 计算公式
**符号**
- a = |wx|，与热力图使用同一未截断的数值。
**步骤**
1. 使用相同 hot_r 背景和 0–25 色条，在单元格中显示 a，统一倍率 x1，保留两位小数。
2. 大于 25 的数字正常显示；CSV 保留未舍入值及 vx_signed、vy_signed。

### 结果解读
- **权重数值表**：直接读取绝对权重，不需要按不同 run 换算显示倍率。
- **固定色条**：数字和颜色表示同一数值，但颜色只区分到 25。

### 质量评价标准
- **权重数值表**：0.00 可能来自舍入、常数输入被剔除或模型系数为零，需查 status 与精确 CSV。
- **固定色条**：超过上限只影响显示颜色，不会把数值修改成 25。

## 图 3：vy weighting heatmap

### 计算公式
**符号**
- wy：模型对应 vy 的原始带符号权重。显示值 a = |wy|。
**步骤**
1. 提取模型 wy，逐位点取绝对值。
2. 按新 mapping 绘制，使用与 vx、norm 完全相同的 hot_r 和 0–25 色条。

### 结果解读
- **权重热力图**：比较不同位置的 vy 权重幅度和各 run 的分布。
- **固定色条**：同样颜色表示同样权重幅度，可与 vx 及 norm 比较。

### 质量评价标准
- **权重热力图**：取绝对值后不再判断速度响应正负方向；灰色与白色含义不同。
- **固定色条**：跨 run 比较仍需保持相同输入尺度和模型口径，统一颜色不消除这些差别。

## 图 4：vy weighting values

### 计算公式
**符号**
- a = |wy|，数值未截断。
**步骤**
1. 在相同 hot_r 背景上显示 a，统一 x1 倍率并保留两位小数。
2. 使用固定 0–25 色条，超过上限的数字继续显示真实幅度。

### 结果解读
- **权重数值表**：直接读取对应位点的 vy 绝对权重。
- **固定色条**：与另外五张图使用相同显示范围。

### 质量评价标准
- **权重数值表**：所有数值图使用统一倍率；精确计算使用 CSV，避免两位小数舍入误差。
- **固定色条**：深色高权重区域内的精细差别需查看数字，不能仅依靠颜色判断。

## 图 5：norm weighting heatmap

### 计算公式
**符号**
- w = sqrt(wx² + wy²)；w 非负，取绝对值后不变。
**步骤**
1. 在同一权重单位下逐位点计算 w。
2. 按 Shank / Elec# 绘制，统一使用 hot_r 和 0–25 色条，不画位置分组曲线。

### 结果解读
- **权重热力图**：显示两个速度分量的综合幅度，不保留方向信息。
- **固定色条**：能用相同数值尺度比较不同 run 的总权重幅度。

### 质量评价标准
- **权重热力图**：norm 不是解释方差或准确率贡献；通道相关性和正则化会影响其大小。
- **固定色条**：norm 通常大于单个分量幅度，不能因为其整体颜色较深就认为模型性能更高。

## 图 6：norm weighting values

### 计算公式
**符号**
- w = sqrt(wx² + wy²)，显示倍率固定为 x1。
**步骤**
1. 在 hot_r 背景上显示 w，保留两位小数，色条固定 0–25。
2. 超过 25 的数值不截断；CSV 保存未舍入 norm 及各分量绝对值和原始带符号值。

### 结果解读
- **权重数值表**：读取单个位点的二维总权重幅度。
- **固定色条**：图上数字和热力图使用相同原始值，色条上限仅约束颜色。

### 质量评价标准
- **权重数值表**：未传输为灰色无数字，常数输入通道为零；不能把两者混同。
- **固定色条**：更大的 norm 不等于更高的模型泛化性能，应同时查看 S10 的 CV 指标。

## 图 7：Active channel depth distribution

### 计算公式
**符号**
- a：某传输通道在本次加载的整段录制中出现任意 code > 0 时为 1，否则为 0。
- d：按 CSV Channel ID 对齐最新 mapping 的深度，单位 µm；Shank1→8 顺序不变，Shank1 原始负深度全部加 106850 µm，从 0 到 6350 µm，纳入统计。
**步骤**
1. 不按 trial 筛选，从整段已加载的神经计数中计算每通道最大 code。code 1、2、3 均只计作一个有效通道。
2. 用 XDF electrode ID 减一连接深度 CSV 的 Channel#。未传输通道不计数。
3. 默认 100 µm 分箱，计算每个深度区间内 a 的总和。图例 n 是本 run 有效通道总数，全部 bins 计数之和等于 n。

### 结果解读
- **深度分布曲线**：横轴是修正后的深度（µm），纵轴 single unit count 是参考图沿用的标签，实际表示有效通道数。
- **图例 n**：每通道最多计一次；不是事件数，也不是 code 数值之和。

### 质量评价标准
- **深度分布曲线**：不表示 spike sorting 分离的神经元数。位置没有对应通道或该 run 未传输时不增加计数，CSV 另列传输覆盖数。
- **图例 n**：使用同一分箱宽度比较 run；记录越长越容易观察到至少一次事件，不能直接把计数差解释成神经元数量变化。

## 注意事项

六张图均没有 position groups 副图。depth_groups CSV 和位置组摘要继续保留供数值统计使用，参数“CSV 位置统计分组 / shank”只影响这些表，不影响任何图。

S14 要求新表格式；布局不可用时明确报错。图内的位点是当前 XDF 选通的子集，不同 run 的传输覆盖可能不同。
