# S15 · 任务回放

**一句话总结：**根据所选记录的 cursor_state 时间戳、位置、速度、目标和 trial 状态，在 GUI「任务回放」标签页或独立 HTML demo 中复现 CO8 / Grid 运动。

## 任务回放

- 点击「播放」默认以 1× 实时播放；可暂停、拖动进度、跳至上一/下一 trial，或选择 0.25×、0.5×、2×、4×。
- 运动位置取已保存的 cursor 位置，速度可选「自动 / 保存速度 / 位置差分」。自动模式在位置有运动而保存速度全部为零或缺失时，显示位置差分速度，并明确标注来源。箭头长度表示该速度持续 0.1 秒的位移，不以速度重新积分替代实测轨迹。
- 原点在屏幕中心，X 向右、Y 向上；回放缩放保持原始宽高比。Grid 网格、CO8 靶大小与 cursor 大小参考该任务保存的配置和日志；配置缺失时会注明示意范围。
- 在同一连续活动 trial 内对相邻位置插值；trial 状态变化或超阈值采样缺口不跨越插值。缺口中隐藏 cursor，显示缺失提示。
- 保留已加载 XDF 范围中的全部 cursor 帧，包括失败、间隔和未进入神经分析队列的 trial；不补齐 XDF 开始前或结束后的行为 CSV 轨迹。
- 独立 HTML demo 无需服务或网络，可双击打开。批次导出也保留 JSON 和 HTML 附件。

### 计算公式

**符号**
- t 为相对首个有效 cursor 时间戳的秒数；(x, y) 为位置；(vx, vy) 为保存的速度，单位 px/s。

**步骤**
1. 每帧相对时间 t = cursor 时间戳 − 首个有效 cursor 时间戳；speed = sqrt(vx² + vy²)。位置差分模式中 vx = Δx/Δt，vy = Δy/Δt，仅使用同一连续活动 trial 内间隔不超过阈值的相邻帧，首帧、复位及缺口处为 N/A。
2. 轨迹使用记录的 (x, y)，并在 trial 切换及超过「采样缺口阈值」的时间间隔处断线；目标来自活动 trial 的 target_x / target_y。
3. 不重新训练解码器，不重新积分速度，不改变保存的辅助控制输出。

### 结果解读

- **Task trajectory**：全段已记录位置与活动目标的概览，用于核对坐标方向和画面范围。
- **Cursor velocity**：所选来源的速度幅值随时间的变化，用于核对播放时序及运动幅度。

### 质量评价标准

- **Task trajectory**：图仅表示已记录轨迹；缺配置时尺寸为示意，无法精确复现未记录的奖励动画、hover 特效、辅助提示或显示延迟。
- **Cursor velocity**：缺失速度显示 N/A；保存的控制输出速度可能与位置差分速度不同，尤其在辅助、边界约束和离散复位附近。位置差分也可能放大采样噪声，不据此推断解码器精度。JSON 的 saved_vx/saved_vy 列保留原始保存速度。
