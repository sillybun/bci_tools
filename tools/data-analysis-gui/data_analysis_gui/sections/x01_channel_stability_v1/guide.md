## 图 1：Electrode Activity and Direction Tuning

### 计算公式
**符号**
- Active 为保留 trial 的分析窗平均发放率存在跨 trial 变异的电极。
- Direction-tuned 为原始方向 ANOVA 经 BH 校正后 q < 0.05 的电极。
- 右轴为该run整体平均成功率（成功次数/全部已知结局尝试次数），并独立展示各block成功率的IQR（Q1–Q3）。各block成功率=成功次数/已知结局尝试次数，包含失败与超时，独立于神经trial筛选。

**步骤**
1. 每份记录去掉分析窗发放率缺失的 trial，统计可检验电极。
2. 对每个可检验电极做方向单因素 ANOVA，在该记录的可检验电极内做 BH 校正。灰柱高度为可检验电极总数，蓝柱从零开始覆盖显著子集。
3. 右轴橙色菱形显示该run整体平均成功率，竖线及端帽独立标记block IQR；优先完整行为CSV，否则仅按XDF记录的完整trial计算。

### 结果解读
- **通道数**：比较每份记录有多少电极可检验，以及其中多少个显著方向调谐。各记录的传输通道数一致时，水平虚线标记该总数。右轴叠加平均成功率与block分布，便于对照行为和通道变化。

### 质量评价标准
- **通道数**：取消16个有效trial的固定门槛。至少2个有限trial即可统计跨trial非零标准差的活跃通道。方向ANOVA还要求至少2个方向且组内残差自由度（trial数−方向数）大于0；不满足时仅调谐通道数为N/A，不能标为0。可检验通道的定义与后续全记录发放率阈值不同。右轴使用全部可核实行为trial，不受神经筛选影响；缺少block结局时不画点。平均值可能落在IQR之外，两者独立绘制。IQR表示block间差异，不是置信区间；双轴仅供对照，不能直接比较两轴高度。

## 图 2：Electrode Maps by Session

实心绿色箭头标记首个匹配的配置，以及后续经电极顺序核实的通道配置变更。将实际传输列与当天及此前的配置匹配，要求完整的 good 和 uncertain 位于前部，其余列来自 bad。沿用同一套分层配置时，即使随机补位变化也不标箭头。有目录配置但无法核实的日期，在该日第一份无法核实的记录上标空心绿色箭头。数据表同时列出目录配置和实际匹配结果。

### 计算公式
**符号**
- `k`：记录编号；`E_k`：第 k 份记录传输的电极 ID 集合（512 个）。
- `M_k(e)`、`S_k(e)`、`R_k(e)`：max code、饱和比例、平均发放率（Hz），定义见图 1。
- `q`：参数「布局图显示量」，取 max_code / saturation / mean_rate。
- 布局图排列：默认 `both`，同时输出 `default` 电极 ID 网格和 `physical` 真实排列，也可单独选择其中一版。
- `V_k(e)`：画在图上的值。
- `pos(e)`：电极 e 在图上的位置。

**步骤**
1. q = max_code：V_k(e) = M_k(e)（离散 0–3）；q = saturation：V_k(e) = max(S_k(e), 1e-5)（对数色标）；q = mean_rate：V_k(e) = log(1 + R_k(e))（色标 0 到所有值的第 99 百分位）。
   意思是：选择要比较的量。
2. 选择 `physical` 且有布局工作簿时 pos(e) = 物理位置（行 0–127，列 A–H）；默认或无工作簿时 pos(e) = （行 = (e − 1) mod 128，列 = ⌊(e − 1) ÷ 128⌋ + 1）。
   意思是：优先按阵列上的真实位置排，否则按 ID 排成 128 × 8。
3. e ∉ E_k 时画灰色。
   意思是：灰色图案就是那天没传输的电极。

### 结果解读
- **每记录布局面板**：逐记录定位当前选择指标的空间分布，对照同电极位置。

### 质量评价标准
- **每记录布局面板**：确保同一色标/指标后比较，灰色为缺传输；成片变化不独立证明电极故障或生理机制。

## 注意事项
- 统计使用每份记录的全部接收帧，不受 trial 筛选影响；记录长度不同（例如 10-27 th120 因断流只有约 31000 帧）会影响 max code（越长越容易出现 3）。
- 状态阈值（0.05 帧饱和、1 Hz）是描述性的分界，不是经过验证的通道质量标准；改参数会改变 stable/unstable 计数。
- 同一天的多份记录在选择顺序中算作相邻记录，转移矩阵会包含同日对。
- 10-27 的三份记录检测阈值不同、10-26 的被试标记为 P001，跨这些记录的差异不能直接解释为跨天变化。

## 图 7：Electrode Overlap and Rate Correlation

### 计算公式
**符号**
- `i`、`j`：两份记录的编号（1…K）。
- `E_i`：第 i 份记录传输的电极 ID 集合（512 个，取自 1–1024）。
- `|A|`：集合 A 里的元素个数；`A ∩ B`：两集合都有的元素；`A ∪ B`：至少一个集合有的元素。
- `C_ij = E_i ∩ E_j`：两份记录共同传输的电极。
- `R_i(e)`：第 i 份记录电极 e 的平均发放率（Hz，定义见图 1）；`M_i(e)`：max code（见图 1）。
- `A_i`：在 C_ij 内 M_i(e) > 0 的电极（至少有过一个事件）。
- `Jaccard`：两个集合的重叠程度，0（完全不重叠）到 1（完全相同）。
- `Pearson r`：线性相关系数，−1 到 1；`mean`：平均；`sd`：标准差。

**步骤**
1. Jaccard_传输(i, j) = |E_i ∩ E_j| ÷ |E_i ∪ E_j|
   意思是：两天传输的电极有多大比例是同一批。
2. shared(i, j) = |C_ij|；对角线 shared(i, i) = |E_i|（通常 512）。
   意思是：两天都能用的电极个数，后续跨天分析只在这些电极上做。
3. 对 e ∈ C_ij，令 u(e) = log(1 + R_i(e))，v(e) = log(1 + R_j(e))。
   意思是：先取对数，避免少数高发放电极主导相关。
4. r(i, j) = Σ (u − mean u)(v − mean v) ÷ (n × sd u × sd v)，n = |C_ij|
   意思是：两天在共同电极上「谁发放高、谁发放低」的排序是否一致。
5. Jaccard_非零(i, j) = |A_i ∩ A_j| ÷ |A_i ∪ A_j|
   意思是：在共同电极中，「有信号的电极」是否是同一批。
6. 下方条带：e ∈ E_k 画蓝色，否则灰色。
   意思是：直接看每份记录传输了哪些 ID。

### 结果解读
- **传输集合 Jaccard**：逐对读取共享/并集电极比例。
- **共享电极数量**：读取每对及对角线传输数量。
- **共享电极 log-rate 相关**：比较 log(1+rate) 的跨电极分布一致性。
- **传输 ID 条带**：按记录查看哪些电极被选入，区分传输缺失与活动为零。
- **非零电极 Jaccard**：在共享传输集合中比较有事件电极身份。

### 质量评价标准
- **传输集合 Jaccard**：集合一致只代表采集通道身份一致，不代表活动相同；低重叠会限制其他稳定性结论。
- **共享电极数量**：分母要足够并明确；少量共享电极的高相关不应推广到整阵列。
- **共享电极 log-rate 相关**：高相关可伴随整体率偏移，低相关也可反映任务差异，需结合散点、共同集合和阈值设置。
- **传输 ID 条带**：只在实际共有电极上比较信号；不能把不同日期的存储列直接当作同一电极。
- **非零电极 Jaccard**：是否非零依赖记录长度和活动稀疏性，不等同于可用性或永久失活。

## 图 8：Electrode Distributions by Session

### 计算公式
**符号**
- `k`：记录编号；`E_k`：第 k 份记录传输的电极 ID 集合（512 个）。
- `M_k(e)`、`S_k(e)`、`R_k(e)`：max code、饱和比例、平均发放率（Hz），定义见图 1。
- `θ_sat`（默认 0.05）、`θ_rate`（默认 1 Hz）：状态阈值，定义见图 1。
- 小提琴图：数值分布的平滑密度轮廓，中间三条横线依次为最小值、中位数、最大值。

**步骤**
1. 左上：n_k(c) = #{e ∈ E_k : M_k(e) = c}，c = 0、1、2、3，按 c 堆叠。
   意思是：每份记录有多少电极最大计数为 0/1/2/3，总高 = 512。
2. 右上：按状态（silent / low / active / saturated）计数并堆叠。
   意思是：每份记录各状态的电极数。
3. 左下：对非静默的传输电极画 log10(max(S_k(e), 1e-6))；虚线 = log10(θ_sat)。
   意思是：有信号电极的饱和比例分布，1e-6 以下画在底部。
4. 右下：对所有传输电极画 log10(1 + R_k(e))；虚线 = log10(1 + θ_rate)。
   意思是：发放率分布，虚线以下即 low 或 silent。

### 结果解读
- **最大编码组成**：逐记录读取各最大编码通道数。
- **状态组成**：比较配置阈值下 silent/low/active/saturated 数量。
- **非静默饱和度分布**：读取每记录 log 饱和比例的分布和尾部。
- **平均率分布**：比较各记录 log(1+Hz) 的位置和离散。

### 质量评价标准
- **最大编码组成**：记录时长、范围不同会改变最大值，不以 max 3 通道多作为质量更好。
- **状态组成**：状态比例无统一理想值，类别边界和通道选择不同须先解释。
- **非静默饱和度分布**：对数零值显示下限不是观测值，注意此面板不含静默组，不能与全通道分母混用。
- **平均率分布**：只比较相同单位和处理范围，群体位移也可来自任务/行为/阈值差异。

## 图 9：Electrode Stability

### 计算公式
**符号**
- `K`：记录份数；`k`：记录编号，按选择顺序（日期顺序）排列。
- `E_k`：第 k 份记录传输的电极 ID 集合（512 个，取自 1–1024）。
- `state_k(e)`：第 k 份记录里电极 e 的状态（silent / low / active / saturated，定义见图 1）。
- `n(e)`：传输电极 e 的记录份数，0…K。
- `stable`：稳定电极；`unstable`：不稳定电极。
- `T(a, b)`：状态转移计数，a = 前一份记录的状态，b = 后一份记录的状态。

**步骤**
1. n(e) = #{k : e ∈ E_k}
   意思是：这个电极在几份记录里被传输。
2. 若 n(e) ≥ 2 且所有满足 e ∈ E_k 的 k 上 state_k(e) 都相同 → stable（按该状态细分）；n(e) ≥ 2 但状态不全相同 → unstable。
   意思是：只要有一次状态变了，就算不稳定；只出现一次的电极不参与判断。
3. T(a, b) = Σ_{k=1…K−1} #{e ∈ E_k ∩ E_{k+1} : state_k(e) = a 且 state_{k+1}(e) = b}
   意思是：相邻两份记录之间，从状态 a 变成状态 b 的电极数，所有相邻对累加。
4. 下方：unstable 电极按 ID 排序，画每份记录的 state_k(e)；超过 300 个时只画覆盖 n(e) 最多的 300 个。
   意思是：看不稳定的电极在哪一天变了。

### 结果解读
- **传输覆盖直方图**：看每电极出现在多少记录中。
- **稳定类别数量**：在至少两次传输的电极中比较同状态与变化状态。
- **相邻记录转换矩阵**：逐起始状态读取后续状态分布。
- **不稳定电极状态条带**：定位具体电极的变化发生在哪次记录。

### 质量评价标准
- **传输覆盖直方图**：未覆盖期间状态未知，不能把缺传输当静默或不稳定。
- **稳定类别数量**：稳定只按离散规则定义，需同时报告覆盖及阈值，不表示保持相同神经单元。
- **相邻记录转换矩阵**：相邻记录不一定相邻自然日，边界转换需结合连续率值和采集配置。
- **不稳定电极状态条带**：多次变化为复查线索而非故障定位，少数次覆盖容易产生片面结论。

## 图 10：Firing Rate Agreement

### 计算公式
**符号**
- `(i, j)`：一对记录，取相邻两份（i, i+1），再加第一份对最后一份。
- `C_ij = E_i ∩ E_j`：两份记录共同传输的电极 ID。
- `R_i(e)`：第 i 份记录电极 e 的平均发放率（Hz，见图 1）；`M_i(e)`：max code（见图 1）。
- `symlog`：对称对数坐标，1 Hz 以下是线性，1 Hz 以上是对数，所以 0 也能画出来。
- `r`：Pearson 相关系数（−1 到 1，定义见图 2）。

**步骤**
1. 每个 e ∈ C_ij 画一个点：x = R_i(e)，y = R_j(e)。
   意思是：同一电极在两天的平均发放率。
2. 若 M_i(e) = 3 或 M_j(e) = 3，点为红色，否则蓝色。
   意思是：红点是可能被 2 bit 上限截断的电极。
3. r = Pearson( log(1 + R_i(e)), log(1 + R_j(e)) )，e ∈ C_ij
   意思是：与图 2 右上同一个数，衡量发放率排序是否保持。
4. 灰线 y = x。
   意思是：点落在线上表示两天发放率相同。
