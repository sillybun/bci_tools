# X02 · 跨 session 传输质量

**一句话总结：**用 S03 的整场口径对比各 session 的 FPGA 缺帧率和长接收间隔时间占比。

## 图 1：Transmission quality across sessions

### 计算公式

**符号**
- L：FPGA 时钟推断缺失的帧数。N：与 FPGA 元数据匹配的接收帧数。
- Δt：相邻神经帧的接收时间差。θ：长接收间隔阈值，默认 150 ms。T：首末接收帧之间的时长。

**步骤**
1. 对每份记录使用完整接收流，计算 A = 100 × L / (N + L)。
2. 计算 B = 100 × Σ(Δt > θ 的完整 Δt) / T。
3. 横轴按日期和文件排序，每份记录等距排列并使用斜体标签。相邻日期之间以淡灰色虚线分隔。同一天的多份记录各自成点，颜色与点形共同区分 Offline CO8、Offline Grid、Online CO8、Online Grid。缺失值标为 N/A，折线在该处断开。

### 结果解读

- **A 整场 FPGA 缺帧率**：比较各记录按独立时钟推断的采集帧缺失比例。
- **B 整场长接收间隔时间占比**：比较长接收间隔的总时长占每份记录首末帧跨度的比例。

### 质量评价标准

- **A 整场 FPGA 缺帧率**：先确认独立时钟可用、元数据匹配充分。N/A 表示无法估计，0% 表示所用时钟步长未推断出缺帧。
- **B 整场长接收间隔时间占比**：对所有记录使用同一阈值。高占比表示接收出现较长空档，可回到 S03 核对空档的次数与位置。
