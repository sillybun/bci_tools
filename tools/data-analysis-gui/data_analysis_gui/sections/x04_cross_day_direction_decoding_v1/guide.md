# X04 · 跨天方向解码准确性

**一句话总结：**对比各记录自身方向解码与共有电极上的跨记录迁移，区分固定训练统计和测试日无标签标准化的表现。

本节回答：**每份记录里，用群体发放率能多准地解码 8 个目标方向？用一天训练的分类器去解码另一天，还剩多少准确率？重新标准化测试日特征能挽回多少？**
数据：所选 ≥2 份记录（按日期排序），每份记录的方向队列（topbar 筛选后的 trial）；特征为分析窗口（默认 T_TRIAL_START 后 0.2–1.2 s）内每个电极的平均发放率（Hz），
标签为 8 个目标方向。跨天训练/测试只用两份记录都传输的电极，按电极 ID 对齐（不同天传输的 512 个子集不同，不按列对齐）。


阅读约定：以下按 subplot 的位置/标题逐项说明；重复的方向、电极、decoder 或记录面板逐个适用对应条目，双轴/色条与主面板合并解释。质量标准区分配置阈值、统计证据与描述性限制，历史数值不作为通用合格线。

## 图 1：Within-day direction decoding

### 计算公式
**符号**
- `k`：记录编号；`t`：trial 编号（方向队列中的第几个 trial）；`e`：电极 ID（1–1024）。
- `x_k(t, e)`：第 k 份记录第 t 个 trial 在分析窗口（默认 T_TRIAL_START 后 0.2–1.2 s）内电极 e 的平均发放率，单位 Hz。
- `y_t`：第 t 个 trial 的目标方向，8 类（0°、45° … 315°）；`Y`：one-hot 标签矩阵（trial 数 × 8，所属方向那一列为 1，其余为 0）。
- `μ_e`、`σ_e`：电极 e 在训练 trial 上的平均值与标准差；`z(t, e) = (x(t, e) − μ_e) ÷ σ_e`，训练集恒定的电极丢弃。
- `Z`：z-score 后的训练特征矩阵（trial 数 × 电极数）；`Zᵀ`：转置；`I`：单位矩阵；`n_train`：训练 trial 数。
- `λ`：ridge 正则强度（参数，默认 1）；`W`：分类器权重（电极数 × 8）；`ŷ_t`：预测方向。
- `BA`：balanced accuracy（平衡准确率），0–1；`recall_d`：方向 d 的 trial 中被正确预测的比例；机会水平 = 1/8 = 0.125。
- `CV`：交叉验证；`block`：任务中连续的一组 trial；`fold`：一折。
- `n_perm`：置换次数（参数，默认 50）；`BA_null`：一次置换后得到的 BA；`p`：置换检验 p 值。
- `confusion(d, d')`：真实方向 d 的 trial 中被预测为 d' 的比例。

**步骤**
1. W = (Zᵀ Z + n_train · λ · I)⁻¹ · Zᵀ · (Y − mean Y)
   意思是：带惩罚的线性回归，把每个方向的 one-hot 标签拟合成电极活动的加权和。
2. ŷ_t = argmax_d [ z(t, ·) · W + mean Y ]_d
   意思是：8 个方向各算一个分数，取最高的那个。
3. recall_d = #{t : y_t = d 且 ŷ_t = d} ÷ #{t : y_t = d}；BA = (1/8) × Σ_d recall_d
   意思是：每个方向分别算正确率再平均，方向数量不均时也公平。
4. 交叉验证：block 按时间顺序分 5 个连续折；训练集去掉与测试 block 相距 ±1 以内的 block；μ_e、σ_e、W 只在训练集上估计。
   意思是：每个 trial 的预测都来自没见过它的模型，且避开相邻 block 的泄漏。
5. 置换：在每个 block 内打乱 y，重做步骤 1–4 得到 BA_null，重复 n_perm 次；p = (1 + #{BA_null ≥ BA}) ÷ (1 + n_perm)。
   意思是：若方向与神经活动无关，BA 能有多高；n_perm = 50 时 p 最小为 0.0196。
6. confusion(d, d') = #{t : y_t = d 且 ŷ_t = d'} ÷ #{t : y_t = d}
   意思是：每一行显示一个真实方向被判成了哪些方向。

### 结果解读
- **日内 BA 与置换参考**：逐记录读取时间 block CV 准确率及经验零分布参照。
- **每记录混淆矩阵**：逐方向看日内的误判结构和方向覆盖。

### 质量评价标准
- **日内 BA 与置换参考**：机会水平和置换应与任务/类别一致；未置换不称显著，不同记录 BA 差异不是阈值效应。
- **每记录混淆矩阵**：高总 BA 不应掩盖某方向失效，比较需要关注样本量及任务类型。

## 图 2：Cross-day accuracy matrices

### 计算公式
**符号**
- `k`：记录编号；`t`：trial 编号（方向队列中的第几个 trial）；`e`：电极 ID（1–1024）。
- `x_k(t, e)`：第 k 份记录第 t 个 trial 在分析窗口（默认 T_TRIAL_START 后 0.2–1.2 s）内电极 e 的平均发放率，单位 Hz。
- `y_t`：第 t 个 trial 的目标方向，8 类（0°、45° … 315°）；`Y`：one-hot 标签矩阵（trial 数 × 8，所属方向那一列为 1，其余为 0）。
- `μ_e`、`σ_e`：电极 e 在训练 trial 上的平均值与标准差；`z(t, e) = (x(t, e) − μ_e) ÷ σ_e`，训练集恒定的电极丢弃。
- `Z`：z-score 后的训练特征矩阵（trial 数 × 电极数）；`Zᵀ`：转置；`I`：单位矩阵；`n_train`：训练 trial 数。
- `λ`：ridge 正则强度（参数，默认 1）；`W`：分类器权重（电极数 × 8）；`ŷ_t`：预测方向。
- `BA`：balanced accuracy（平衡准确率），0–1；`recall_d`：方向 d 的 trial 中被正确预测的比例；机会水平 = 1/8 = 0.125。
- `i`：训练记录（行）；`j`：测试记录（列）。
- `C_ij`：两份记录都传输的电极 ID（按 ID 对齐，不按存储列），去掉训练日恒定的电极。
- `μ_i,e`、`σ_i,e` / `μ_j,e`、`σ_j,e`：第 i 天 / 第 j 天全部 trial 上电极 e 的均值与标准差。
- 测试日标准化（参数「测试日特征标准化」，默认两种都画）：`fixed`（= train，用第 i 天统计量）、`re-standardized`（= test_own，用第 j 天自己的统计量）。
- `W_i`：第 i 天全部 trial 在 C_ij 上训练的权重（图 1 步骤 1）；`BA_j←i`：用 W_i 解码第 j 天得到的 BA。
- `n_perm`：置换次数；`p`：置换 p 值；红框 = p ≥ 0.05。

**步骤**
1. 训练：z_i(t, e) = (x_i(t, e) − μ_i,e) ÷ σ_i,e，e ∈ C_ij；用第 i 天全部 trial 按图 1 步骤 1 得到 W_i。
   意思是：用训练日的全部数据拟合一个分类器，不做交叉验证。
2. 测试：fixed：z_j(t, e) = (x_j(t, e) − μ_i,e) ÷ σ_i,e；re-standardized：z_j(t, e) = (x_j(t, e) − μ_j,e) ÷ σ_j,e。
   意思是：fixed 完全照搬训练日；re-standardized 只把测试日特征重新换算成它自己的 z-score，权重不变。
3. ŷ_t = argmax_d [ z_j(t, ·) · W_i + mean Y_i ]_d；BA_j←i 按图 1 步骤 3 计算（第 j 天全部 trial）。
   意思是：训练日的模型在测试日的平衡准确率。
4. 跨天置换：预测 ŷ 不变，在第 j 天每个 block 内打乱 y 重算 BA，重复 n_perm 次；p = (1 + #{BA_null ≥ BA_j←i}) ÷ (1 + n_perm)。
   意思是：检验固定预测与真实方向是否有关联。
5. 对角线 i = j：日内 CV 的 BA（全部传输电极，图 1）。右图：|C_ij|，对角线 = 当天非恒定电极数。
   意思是：对角线是当天自己的水平。

### 结果解读
- **固定训练均值/SD 矩阵**：行训练记录、列测试记录，读取不使用测试日统计的迁移 BA。
- **测试日重新标准化矩阵**：比较只调整测试特征均值/SD 后的 BA。
- **共有非恒定电极数矩阵**：核对每个迁移格子的共同电极数量。

### 质量评价标准
- **固定训练均值/SD 矩阵**：对角线为日内 CV，非对角为全训练记录拟合；只在共有电极上评估，不能当作纯日期效应。
- **测试日重新标准化矩阵**：使用了测试分布信息，属于无标签校准而非全固定部署；改善不独立证明问题仅来自漂移。
- **共有非恒定电极数矩阵**：电极集合改变会混杂性能，少量共享时不宜比较相同色深。

## 图 3：Accuracy vs days apart

### 计算公式
**符号**
- `(i, j)`：有序记录对，i ≠ j，i = 训练记录，j = 测试记录。
- `Δd(i, j)`：两份记录文件夹日期相差天数的绝对值，同日 = 0。
- `BA_j←i`：图 2 的跨天平衡准确率（fixed 或 re-standardized 各一张小图）。
- `BA_k`：第 k 份记录的日内 CV 平衡准确率（图 1）。
- `slope`：最小二乘直线斜率（每天的变化量）。

**步骤**
1. 每个有序对画一点：x = Δd(i, j) + 少量水平抖动，y = BA_j←i。
   意思是：跨天准确率随相隔天数怎么变。
2. 选择顺序 j > i 为蓝点（训练在前、测试在后），否则为橙方块。
   意思是：区分「向后迁移」和「向前迁移」。
3. y ≈ slope × Δd + 截距（所有点最小二乘）。
   意思是：slope 是平均每天损失的准确率。
4. 绿色菱形：x = −0.4，y = BA_k；右下角文字 = 测试日 BA 的平均。
   意思是：日内上限参考，点与菱形的差距就是跨天损失。

### 结果解读
- **左侧固定统计迁移**：按时间间隔读 fixed 特征的跨记录 BA。
- **右侧测试日标准化迁移**：查看无标签校准后时间间隔关系是否变化。

### 质量评价标准
- **左侧固定统计迁移**：点对共享训练/测试记录，非独立观察；未给不确定性时不下显著趋势结论。
- **右侧测试日标准化迁移**：与左图同一对记录比较，但不能把群体差异归因于某一天或阈值；图中同日间隔不是零漂移保证。

## 注意事项
- 对角线（日内 CV）使用当天全部传输电极，非对角线只用共同电极（约 275–380 个），两者电极集合不同；相同电极集合上的日内上限见 X06。
- 跨天训练用了训练日全部 trial，没有交叉验证——测试日的 trial 从未参与训练，因此不存在泄漏。
- 跨天置换只打乱测试日标签，检验的是「固定预测与真实方向是否有关联」，不包含训练过程的随机性。
- 10-27 三份记录检测阈值不同，跨这些记录的 fixed 结果主要反映阈值差异；10-26 的被试标记为 P001。
- 「天数」按记录文件夹日期计算，同日多份记录天数为 0。
