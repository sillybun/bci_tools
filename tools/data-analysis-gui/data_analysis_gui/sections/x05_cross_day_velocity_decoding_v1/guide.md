# X05 · 跨天速度解码准确性 r2 rmse

**一句话总结：**在统一速度评估协议下比较日内与跨记录解码的 R²、误差和运动尺度，评价迁移损失及模型差异。

本节回答：**每份记录自身的速度解码有多准？用第 i 天训练的模型直接用于第 j 天，还剩多少？**
数据：每份所选记录的速度队列，每个 trial 从 T_TRIAL_START + 0.2 s 起 10 个 100 ms bin。不同日期传输的 512/1024 电极不同，
跨天比较只用两天都传输的电极 ID（不按列号）。速度解码固定为 Ridge 和 Vel-KF。


阅读约定：以下按 subplot 的位置/标题逐项说明；重复的方向、电极、decoder 或记录面板逐个适用对应条目，双轴/色条与主面板合并解释。质量标准区分配置阈值、统计证据与描述性限制，历史数值不作为通用合格线。

## 图 1：Within-day velocity and position

### 计算公式
**符号**
- v 是逐 bin 速度；p₀ 是 trial 的真实起始位置。位置预测为 p₀ + Σ v̂·Δt。

**步骤**
1. 使用同一记录内 block CV 的留出速度预测，在两模型共有的有效 bin 上计算 x、y 平均 R²。
2. 位置只使用从首 bin 开始且连续的 trial，比较积分后每个 bin 的右端位置。点为 R²，误差线为 200 次 block bootstrap 的 95% 区间。

### 结果解读
- **Velocity**：比较每份记录的速度解码。
- **Position**：比较速度积分后的位置重建。

### 质量评价标准
- **Velocity**：两模型使用相同的测试 bin，n 表示参与评分的 trial 数。
- **Position**：起始位置用于初始化，评分只包括预测端点。位置与速度的有效 trial 数可能不同。

## 图 3：Within-day velocity decoding

### 计算公式
**符号**
- `i`、`j`：记录（天）编号；i = 训练记录，j = 测试记录。
- `v_k`：第 k 个 100 ms bin 的真实 cursor 速度 = (bin 右端位置 − 左端位置) ÷ 0.1 s（任务坐标单位/s）。
- `x_k`：特征 = 截至 bin 右端尾随 200 ms 窗口的每电极平均发放率（Hz）；`共同电极`：i、j 两天都传输的电极 ID。
- `μ_i`、`σ_i`：训练记录 i 上每个电极特征的均值与标准差；`μ_j`、`σ_j`：测试记录 j 自身的均值与标准差。
- `v̂_k`：decoder 预测；`SSE`、`SST`：按轴的误差平方和与总平方和；`R²`：(R²_x + R²_y) ÷ 2，每轴 R² = 1 − SSE/SST。
- `RMSE`：sqrt((MSE_x + MSE_y) ÷ 2)，MSE 为每轴均方误差（任务坐标单位/s）。
- `fold`：日内交叉验证的一折（block 按时间分 5 组，训练集去掉测试组 ±1 的 block）。
- Ridge 和 Vel-KF 的模型定义见 S10。
- `RMS 速度`：sqrt(mean ‖v_k‖²)，记录的典型速度大小。

**步骤**
1. 日内交叉验证：每折在训练 block 上拟合（归一化只用训练行），预测测试 block，得到 held-out v̂_k。
   意思是：每份记录自己能解码到多好。
2. R² = (R²_x + R²_y) ÷ 2，每轴 R² = 1 − SSE ÷ SST。
   意思是：两个方向的解码好坏取平均，1 为完美、0 等于猜均值。
3. RMSE = sqrt((MSE_x + MSE_y) ÷ 2)。
   意思是：两个方向合起来的典型误差大小。
4. 右图：RMS 速度 = sqrt(mean ‖v_k‖²)。
   意思是：RMSE 的量纲参照，速度小的记录 RMSE 天然小。

### 结果解读
- **左侧日内 R²**：对每记录逐模型比较自身 block CV 的平均 x/y R²。
- **中间日内 RMSE**：读取相同单位下模型误差的记录差异。
- **右侧 cursor 速度尺度**：看每记录速度的 RMS 作为误差参考。

### 质量评价标准
- **左侧日内 R²**：需结合样本及任务差异；R²≤0 为未优于对应均值基线，日内好不保证跨天好。
- **中间日内 RMSE**：与右侧速度尺度共同判断，不能将较低幅度任务的低误差直接判为信号更好。
- **右侧 cursor 速度尺度**：速度幅度不同会改变 R²/RMSE，可比性需限定任务、单位及窗口，在线 cursor 仍是闭环量。

## 图 4：Cross-day R2 and RMSE matrices

### 计算公式
**符号**
- `i`、`j`：记录（天）编号；i = 训练记录，j = 测试记录。
- `v_k`：第 k 个 100 ms bin 的真实 cursor 速度 = (bin 右端位置 − 左端位置) ÷ 0.1 s（任务坐标单位/s）。
- `x_k`：特征 = 截至 bin 右端尾随 200 ms 窗口的每电极平均发放率（Hz）；`共同电极`：i、j 两天都传输的电极 ID。
- `μ_i`、`σ_i`：训练记录 i 上每个电极特征的均值与标准差；`μ_j`、`σ_j`：测试记录 j 自身的均值与标准差。
- `v̂_k`：decoder 预测；`SSE`、`SST`：按轴的误差平方和与总平方和；`R²`：(R²_x + R²_y) ÷ 2，每轴 R² = 1 − SSE/SST。
- `RMSE`：sqrt((MSE_x + MSE_y) ÷ 2)，MSE 为每轴均方误差（任务坐标单位/s）。
- `fixed` / `recentre` / `test_own`：三种测试日标准化方式（见步骤 2）。
- `对角线`：i = j，日内交叉验证；`非对角 (i, j)`：i 训练、j 测试。

**步骤**
1. 非对角 (i, j)：在第 i 天全部 bin 上拟合（只用共同电极），直接预测第 j 天全部 bin，算 R² 与 RMSE。
   意思是：模型训练完就不再改，看隔天还剩多少。
2. 测试日标准化（参数 test_standardize），模型看到的标准化特征为：
   fixed（train）：(x − μ_i) ÷ σ_i；recentre：(x − μ_j) ÷ σ_i；test_own：(x − μ_j) ÷ σ_j。
   意思是：fixed 完全不改；recentre 先去掉测试日自身均值；test_own 再把尺度也换成测试日的。
3. 实现：把测试特征换算成 x' 使 decoder 内部的训练归一化恰好得到上式（recentre：x' = x − μ_j + μ_i；test_own：x' = (x − μ_j) ÷ σ_j × σ_i + μ_i）。
   意思是：对所有 decoder 用同一套规则，不重新拟合任何权重。
4. 对角线：当天全部传输电极的日内交叉验证（同图 1）。
   意思是：对角线是每天自己能达到的水平，作为参照。
5. 右上：共同且在第 i 天非恒定（σ_i > 0）的电极数。
   意思是：共同电极越多，跨天比较越可靠。

### 结果解读
- **每 decoder 的 R² 矩阵**：逐行训练、逐列测试查看迁移；按数值和负值标记读低于色标范围的结果。
- **每 decoder 的 RMSE 矩阵**：与同一模型 R² 格子对照，区分幅度和归一化指标。
- **共有非恒定电极数**：核对迁移使用的电极数量。
- **协议说明文字**：核对训练/测试方向、对角线定义和 test_standardize 模式。

### 质量评价标准
- **每 decoder 的 R² 矩阵**：对角线日内 CV 和非对角全训练拟合需区分，不能靠色深比较被截色的负 R²。
- **每 decoder 的 RMSE 矩阵**：单位/运动尺度及共有测试 bin 必须一致；R² 与 RMSE 反映不同方面。
- **共有非恒定电极数**：每对集合不同，通道覆盖和时间漂移不能直接分离，少量共同电极应限制结论。
- **协议说明文字**：测试日重新标准化使用本日分布信息，不能称作完全不适应的固定模型。

## 图 5：Velocity transfer vs days apart

### 计算公式
**符号**
- `i`、`j`：记录（天）编号；i = 训练记录，j = 测试记录。
- `v_k`：第 k 个 100 ms bin 的真实 cursor 速度 = (bin 右端位置 − 左端位置) ÷ 0.1 s（任务坐标单位/s）。
- `x_k`：特征 = 截至 bin 右端尾随 200 ms 窗口的每电极平均发放率（Hz）；`共同电极`：i、j 两天都传输的电极 ID。
- `μ_i`、`σ_i`：训练记录 i 上每个电极特征的均值与标准差；`μ_j`、`σ_j`：测试记录 j 自身的均值与标准差。
- `v̂_k`：decoder 预测；`SSE`、`SST`：按轴的误差平方和与总平方和；`R²`：(R²_x + R²_y) ÷ 2，每轴 R² = 1 − SSE/SST。
- `RMSE`：sqrt((MSE_x + MSE_y) ÷ 2)，MSE 为每轴均方误差（任务坐标单位/s）。
- `|days apart|`：两份记录日历日期差的绝对值（天）；同一天不同 run 为 0。
- `抖动`：为避免重叠，横坐标加 ±0.12 的随机偏移，不同 decoder 再错开 0.15。

**步骤**
1. 每个有序对 (i → j) 一个点：横轴 |days apart|，纵轴为该对的 transfer R² 或 RMSE（同图 2 的非对角）。
   意思是：i→j 与 j→i 分别算，各是一个点。
2. x = −0.5 处的空心菱形：每份记录的日内交叉验证值。
   意思是：把「隔了几天」和「掉了多少」放在一起看。

### 结果解读
- **左侧 R² 随间隔**：分模型观察每个有向记录对的迁移分数。
- **右侧 RMSE 随间隔**：与左图配对读取误差和间隔关系。

### 质量评价标准
- **左侧 R² 随间隔**：负值不应隐藏，点对非独立，不能把趋势线解释为随时间必然退化。
- **右侧 RMSE 随间隔**：需考虑测试日运动尺度；日间隔相同不代表同一难度或相同通道集合。

## 图 6：Decoder comparison

### 计算公式
**符号**
- `i`、`j`：记录（天）编号；i = 训练记录，j = 测试记录。
- `v_k`：第 k 个 100 ms bin 的真实 cursor 速度 = (bin 右端位置 − 左端位置) ÷ 0.1 s（任务坐标单位/s）。
- `x_k`：特征 = 截至 bin 右端尾随 200 ms 窗口的每电极平均发放率（Hz）；`共同电极`：i、j 两天都传输的电极 ID。
- `μ_i`、`σ_i`：训练记录 i 上每个电极特征的均值与标准差；`μ_j`、`σ_j`：测试记录 j 自身的均值与标准差。
- `v̂_k`：decoder 预测；`SSE`、`SST`：按轴的误差平方和与总平方和；`R²`：(R²_x + R²_y) ÷ 2，每轴 R² = 1 − SSE/SST。
- `RMSE`：sqrt((MSE_x + MSE_y) ÷ 2)，MSE 为每轴均方误差（任务坐标单位/s）。
- `日内 R²`：每份记录自己的 5 折 block 交叉验证 R²（图 1）。
- `transfer R²`：i 训练、j 测试（i ≠ j）的 R²（图 2 非对角），使用当前 test_standardize。
- `跨天损失`：平均日内 R² − 平均 transfer R²。

**步骤**
1. (a)：热图，行 = decoder，列 = 记录，值 = 日内 R²。
   意思是：每份记录上各 decoder 的日内水平。
2. (b)：空心柱 = 各记录日内 R² 的平均；实心柱 = 所有有序对 i ≠ j 的 transfer R² 平均；黑点 = 每个有序对。
   意思是：空心柱与实心柱的落差就是跨天损失。
3. (c, d)：按 |days apart| 分组对 transfer R²、RMSE 取平均，x = 0 处为日内平均。只选一个 decoder 时仍出图，标题注明。
   意思是：看性能是否随相隔天数增加而下降。

### 结果解读
- **A 日内各记录 R²**：看模型自身日内能力及记录差异。
- **B 日内与迁移配对分布**：看每模型的日内分数与所有有向迁移对的差距。
- **C R² 与日间隔**：同图对照多个模型的迁移趋势，零间隔处区分日内与同日跨记录。
- **D RMSE 与日间隔**：检查模型误差随时间距离的变化。

### 质量评价标准
- **A 日内各记录 R²**：只比较同协议与共同测试集合，不把最好记录当作整体表现。
- **B 日内与迁移配对分布**：不同对重复使用记录而非独立样本；差距还受共有电极子集影响。
- **C R² 与日间隔**：不据视觉线条宣称显著优越或日期因果效应，负 R² 要按数值读。
- **D RMSE 与日间隔**：比较同时参考 RMS 速度及记录协议，不按固定 RMSE 线判断质量。

## 注意事项
- 速度队列规则来自 Topbar 的 TrialFilter（velocity_bin_policy：drop_trial 去掉含坏 bin 的整个 trial、drop_bin 只去坏 bin；cursor 空档、神经窗口、最少帧数、最大空档），方法文本中逐项写明。
- R² 可以为负（比直接预测训练日平均速度还差）；fixed 标准化下的强负值主要反映偏置失配，不一定说明方向调谐完全变了——用 recentre / test_own 对照判断。
- 跨记录结果是描述性比较，不能单独解释为阈值或因果效应。
- SDK decoder（尤其 ReFIT-KF 逐帧回放）较慢：两份记录、五个 decoder 约 1.5 分钟。
