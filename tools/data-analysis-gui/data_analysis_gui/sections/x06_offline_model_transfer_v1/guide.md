# X06 · 离线模型跨天分析

**一句话总结：**以指定参考记录训练固定模型，比较跨记录迁移、无标签再校准和相同电极日内参照，并报告闭环解释限制。

本节回答：**在参考记录上训练的离线模型，固定权重后用到其他记录上还剩多少性能？只做简单的特征再校准能挽回多少？**

「参考记录」下拉框列出已勾选的记录。指定某份记录时，测试其余全部已勾选记录，包含日期更早的记录。`first` 从第一份向后测试，`each` 对每份有后续记录的参考向后测试。

参考记录用其全部 trial / bin 训练：
- 方向分类器：trial 窗口平均发放率上的 one-hot ridge（λ = lam）。
- 速度解码固定为 Ridge 与 Vel-KF。

速度 bin：速度队列，每 trial 从 T_TRIAL_START + 0.2 s 起 10 个 100 ms bin。所有比较只用参考与测试两份记录都传输的电极 ID。


阅读约定：以下按 subplot 的位置/标题逐项说明；重复的方向、电极、decoder 或记录面板逐个适用对应条目，双轴/色条与主面板合并解释。质量标准区分配置阈值、统计证据与描述性限制，历史数值不作为通用合格线。

## 图 1：Fixed-model performance vs days elapsed

### 计算公式
**符号**
- `r`：参考记录（用于训练模型）；`j`：测试记录。早于参考日期的测试记录显示为负天数。
- `μ_r`、`σ_r`：参考记录每个电极特征的均值与标准差；`μ_j`、`σ_j`：测试记录自身的均值与标准差。
- `fixed` / `re-centred` / `re-standardized`：三种测试日标准化方式（见步骤）。
- `v_k`：第 k 个 100 ms bin 的真实 cursor 速度 = (右端位置 − 左端位置) ÷ 0.1 s；`v̂_k`：decoder 预测。
- `R²`：(R²_x + R²_y) ÷ 2，每轴 R² = 1 − SSE/SST（SSE 误差平方和，SST 总平方和）。
- `recall_d`：方向 d 的 trial 中被分对的比例；`balanced accuracy`：8 个 recall_d 的平均，机会水平 = 1/8。
- `ceiling`（上限）：测试记录 j 在同一批共同电极上的日内 5 折 block 交叉验证（±1 block purge）结果。
- `reference CV`：参考记录自身在全部电极上的日内交叉验证结果。
- `baseline`（基线）：方向准确率为 1/8，R² 为 0。
- `retention`（保留率）：(transfer − baseline) ÷ (ceiling − baseline)。
- `x 位置`：距参考的天数 + 0.12 × 同日 run 序号。

**步骤**
1. 拟合：模型在参考记录 r 的全部 trial / bin 上只拟合一次（只用 r、j 共同电极），之后不再改权重。
   意思是：模型训练完就固定下来，模拟「之后几天不再校准」。
2. 测试日标准化：fixed：(x − μ_r) ÷ σ_r；re-centred：(x − μ_j) ÷ σ_r；re-standardized：(x − μ_j) ÷ σ_j。
   意思是：fixed 完全不改；re-centred 只修正均值漂移；re-standardized 连尺度一起修正。速度 decoder 通过把测试特征换算成 x' 实现，对所有 decoder 等价。
3. 方向：balanced accuracy = (Σ_d recall_d) ÷ 8。
   意思是：每个方向分对的比例取平均，不受方向 trial 数不同的影响。
4. 速度：在 j 的全部速度 bin 上算 R²（20 ms decoder 的预测先按 5 个取平均回到 100 ms）。
   意思是：固定模型在测试日全部数据上的速度解码好坏。
5. 菱形 = ceiling；x = 0 的星号 = reference CV；R² < −1 画成底部三角形。
   意思是：曲线与菱形之间的距离就是时间造成的损失。

### 结果解读
- **方向分类面板**：逐测试记录比较固定、去均值、重标准化模式与日内参照的 BA。
- **各 decoder 速度 R² 面板**：对每种速度模型分别查看各校准模式在测试记录上的性能。

### 质量评价标准
- **方向分类面板**：基线机会水平与日内参照须按同电极/同任务解释，参照不是理论上限；无标签再校准使用测试分布信息。
- **各 decoder 速度 R² 面板**：训练参考与测试记录方向明确，负 R² 表示未优于对应均值基线，不能由单个好点宣称长期稳定。

## 图 2：Retention relative to within-day ceiling

### 计算公式
**符号**
- `r`：参考记录（训练模型的那一天）；`j`：比 r 更晚的测试记录。
- `μ_r`、`σ_r`：参考记录每个电极特征的均值与标准差；`μ_j`、`σ_j`：测试记录自身的均值与标准差。
- `fixed` / `re-centred` / `re-standardized`：三种测试日标准化方式（见步骤）。
- `v_k`：第 k 个 100 ms bin 的真实 cursor 速度 = (右端位置 − 左端位置) ÷ 0.1 s；`v̂_k`：decoder 预测。
- `R²`：(R²_x + R²_y) ÷ 2，每轴 R² = 1 − SSE/SST（SSE 误差平方和，SST 总平方和）。
- `recall_d`：方向 d 的 trial 中被分对的比例；`balanced accuracy`：8 个 recall_d 的平均，机会水平 = 1/8。
- `ceiling`（上限）：测试记录 j 在同一批共同电极上的日内 5 折 block 交叉验证（±1 block purge）结果。
- `reference CV`：参考记录自身在全部电极上的日内交叉验证结果。
- `baseline`（基线）：方向准确率为 1/8，R² 为 0。
- `retention`（保留率）：(transfer − baseline) ÷ (ceiling − baseline)。

**步骤**
1. retention = (transfer − baseline) ÷ (ceiling − baseline)，方向的 baseline = 1/8，R² 的 baseline = 0。
   意思是：1 = 和测试日自己重训一样好，0 = 只到基线，负数 = 比基线还差。
2. ceiling − baseline ≤ 1e-6 时不计算；结果截断到 [−1, 1.5]；每个（参考, 测试, 标准化）一个点。
   意思是：上限本身接近基线时比例没有意义，所以不画。

### 结果解读
- **方向保留比例面板**：读取扣除机会水平后的迁移增益相对测试日内参照增益。
- **各 decoder 速度保留比例面板**：比较迁移 R² 除以匹配电极的日内 R²。

### 质量评价标准
- **方向保留比例面板**：日内参照接近机会水平时比例不稳定或未定义，超过 1 不代表超过理论能力上限。
- **各 decoder 速度保留比例面板**：日内 R² 小、为零或负时比例不可正常解释，需回到原始 R²；图的裁剪不代表真实值被限制。

## 图 3：Online recordings: decoder output vs cursor velocity

### 计算公式
**符号**
- `o_k`：在线 decoder 流在第 k 个速度 bin 右端时刻的线性插值（二维速度）。
- `v_k`：该 bin 的 cursor 位移速度（任务坐标单位/s）。
- `r`：x、y 两轴 Pearson 相关的平均；`R²`：x、y 两轴 R² 的平均（以 v_k 为参考）。
- `gain`（增益）：最小二乘比例系数，使 v ≈ gain × o。

**步骤**
1. 对齐：o_k = 在线 decoder 样本在 bin 右端时刻的线性插值。
   意思是：把在线输出放到与 cursor 速度相同的时刻上比较。
2. 一致性：r、R² 按轴计算后取平均。
   意思是：两个方向分别算，再平均。
3. 增益：gain = Σ_k (o_k · v_k) ÷ Σ_k ‖o_k‖²。
   意思是：cursor 速度约是在线输出的几倍；偏离 1 说明 cursor 对 decoder 输出做了缩放或平滑。
4. 右图：前 300 个 bin 的 v_x 与 o_x。只在所选记录有 cursortasks_decoder_velocity 流时出现。
   意思是：直接看两条曲线是否重合。

### 结果解读
- **每在线记录 x 散点**：看记录 decoder vx 与 cursor vx 的比例、偏置和相关。
- **每在线记录 y 散点**：独立检查 vy 的一致性和偏离。
- **每在线记录速度时间条**：在图示 bin 范围比较输出与 cursor 的动态变化。

### 质量评价标准
- **每在线记录 x 散点**：两者闭环耦合且可能存在平滑/缩放，不能作为独立神经泛化验证。
- **每在线记录 y 散点**：与 x 和同记录单位/对齐共同判断，不能只用更好的轴代表在线质量。
- **每在线记录速度时间条**：仅是局部闭环一致性，无在线流时显示不可用，不把缺流解释为零性能。

## 图 4：Decoder comparison

### 计算公式
**符号**
- `r`：参考记录（训练模型的那一天）；`j`：比 r 更晚的测试记录。
- `μ_r`、`σ_r`：参考记录每个电极特征的均值与标准差；`μ_j`、`σ_j`：测试记录自身的均值与标准差。
- `fixed` / `re-centred` / `re-standardized`：三种测试日标准化方式（见步骤）。
- `v_k`：第 k 个 100 ms bin 的真实 cursor 速度 = (右端位置 − 左端位置) ÷ 0.1 s；`v̂_k`：decoder 预测。
- `R²`：(R²_x + R²_y) ÷ 2，每轴 R² = 1 − SSE/SST（SSE 误差平方和，SST 总平方和）。
- `recall_d`：方向 d 的 trial 中被分对的比例；`balanced accuracy`：8 个 recall_d 的平均，机会水平 = 1/8。
- `ceiling`（上限）：测试记录 j 在同一批共同电极上的日内 5 折 block 交叉验证（±1 block purge）结果。
- `reference CV`：参考记录自身在全部电极上的日内交叉验证结果。
- `baseline`（基线）：方向准确率为 1/8，R² 为 0。
- `retention`（保留率）：(transfer − baseline) ÷ (ceiling − baseline)。
- `R²_ceiling`：ceiling 的速度 R²；本图 retention 只用速度，baseline = 0。

**步骤**
1. 上排（三种标准化各一幅）：每个 decoder 一条线，从 x = 0 的 reference CV（星号）连到各测试记录的 transfer R²；多个参考时同一 x 的值取平均；
   空心菱形 = ceiling；R² < −1 画成 ▼ 并标出数值；同一 x 上不同 decoder 稍微左右错开。
   意思是：同一种标准化下比较各 decoder 跨天掉了多少。
2. 下排：retention = transfer R² ÷ R²_ceiling（R²_ceiling ≤ 1e-6 的配对丢弃，截断到 [−1, 1.5]）；柱 = 所有配对的平均，点 = 每个配对；每个 decoder 三根柱，从浅到深为 fixed、re-centred、re-standardized。
   意思是：直接比较各 decoder 跨天保留了多少，以及简单再校准挽回了多少。只选一个 decoder 时仍出图，标题注明。

### 结果解读
- **固定测试统计面板**：对每 decoder 读取固定模式迁移、参考 CV 和匹配日内参照。
- **测试日去均值面板**：检查只调整均值后的迁移变化。
- **测试日重标准化面板**：查看均值和 SD 都调整后的各模型表现。
- **保留比例分布面板**：读取各模型/校准的平均及有向记录对分布，并对照原始分数表。

### 质量评价标准
- **固定测试统计面板**：三类点采用不同训练/测试来源，不能直接当作相同重复；低于显示范围的负值用标记注明。
- **测试日去均值面板**：使用测试日无标签信息，改善可支持分布偏移线索但不证明唯一机制。
- **测试日重标准化面板**：与前两图逐对记录比较，不能把同数据选出的最好模式当作独立部署结果。
- **保留比例分布面板**：显示可能裁剪到 [−1,1.5]，参照分母接近零时不稳定，不能只比较柱高宣称模型优越。

## 注意事项
- 速度队列规则来自 Topbar 的 TrialFilter（velocity_bin_policy：drop_trial / drop_bin；cursor 空档、神经窗口、最少帧数、最大空档），方法文本中逐项写明。
- 「再校准」只改测试日特征的均值 / 标准差，不重新拟合任何权重；re-standardized 需要测试日的数据统计量，严格来说不是完全零校准。
- 在线记录中 cursor 速度是在线 decoder 的输出（闭环），与离线开环日的速度不是同一种行为量；离线模型在在线记录上的表现不能直接与开环日比较。
- 参考 = each 时，每份有后续记录的记录轮流作参考，图中线型区分参考；只有两份记录时与 first 等价。
