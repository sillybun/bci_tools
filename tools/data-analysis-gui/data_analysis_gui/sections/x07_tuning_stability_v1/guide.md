# X07 · 方向调谐与 PSTH 跨天稳定性

**一句话总结：**按电极 ID 对齐，用 S05 八方向调谐和 S06 时间响应分别统计电极可维持稳定的天数，并展示两端的排名示例。

同日多个 run 先合并，每个可检验 run 等权。某天显著要求该电极当天的每个可检验 run 都通过来源检验，PSTH 还要求各 run 的响应符号一致。分析沿用顶栏 trial 筛选和单日 S05、S06 参数。方向使用 S05 原始 ANOVA，至少每个方向 2 个有效 trial。PSTH 比较 S06 对齐事件后相对于同 trial 基线的原始响应曲线，每个用于比较的 bin 至少有 3 对有效样本。

已知异常日期可在「排除日期」填写，例如 `1026,1027,1105`。它们当天的所有 run 都从 X07 排除。剩余至少三天时，系统还逐个尝试移除一天。单电极容错值取严格结果与这些结果中的最大值，跳过的日期不计入稳定天数。不同电极可能跳过不同日期。查看 `leave_one_date_out` 可比较同一天对全体电极的影响。结果用于判断对个别日期的敏感程度，无法单凭此表确认采集故障。

## 图 1：Tuning stability by number of days

### 计算公式

**符号**

- (r) 为两天平均曲线的 Pearson 相关，至少需要 3 个共有有效值。
- (L) 为最长稳定段包含的所选日期数。只在至少两天可检验的电极上汇总。

**步骤**

1. 两天都显著、且 (r) 达到设置下限才可能稳定。方向还要求环形偏好方向差不超过设置上限，PSTH 还要求响应符号相同。
2. 找出满足段内任意两天都稳定的最长日期段。所选日期中缺测或无法检验的日期打断该段。未选的自然日不计入长度。
3. 每种口径下，每个电极归入一个柱。0 表示没有显著日期，1 表示有显著日期但没有至少两天的稳定段。严格和容错口径的可比较电极总数相同。

### 结果解读

- **方向与 PSTH 分布**：柱高是最长稳定段恰为该天数的电极数。两种分析各有自己的可比较电极总数。

### 质量评价标准

- **方向与 PSTH 分布**：同时查看覆盖天数、显著天数和缺测情况。稳定表示同一电极触点的曲线一致，不能据此确认同一神经元。

## 图 2：DIRECTION tuning examples

### 计算公式

**符号**

- (f(d)) 为方向 (d) 的平均发放率，单位 Hz。

**步骤**

1. 取至少两天可检验且至少一天显著的电极。默认先按容错稳定天数，再按严格稳定天数、稳定日期对比例、平均曲线相关、可检验天数及电极 ID 排序。可取消勾选「示例按容许跳过一天排序」。
2. 展示排名两端。每条线是一份按日期合并的八方向曲线，实线表示当天显著，虚线表示当天可检验但未达到显著条件。

### 结果解读

- **示例曲线**：对照各天的峰值方向和曲线形状，看哪些电极偏好方向保持或发生变化。

### 质量评价标准

- **示例曲线**：缺测日期没有曲线。排名同时考虑显著性和形状，单看发放率幅度不能复现排名。

## 图 3：PSTH tuning examples

### 计算公式

**符号**

- (Delta f(t)) 为对齐事件后各 bin 的平均配对发放率差，单位 Hz。

**步骤**

1. 采用与方向示例相同的排名顺序，使用 PSTH 自己的稳定段、稳定日期对比例和相关。
2. 每条线是一份按日期合并的基线校正响应，实线表示当天显著且可检验 run 的响应符号一致，虚线表示当天可检验但未达到该条件。

### 结果解读

- **示例曲线**：对照各天的响应上升或下降方向，以及事件后响应的时间形状。

### 质量评价标准

- **示例曲线**：检查对齐事件、基线和 bin 设置。对齐点变化或基线数据不足会影响比较。
