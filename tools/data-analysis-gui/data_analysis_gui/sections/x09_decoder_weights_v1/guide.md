# X09 · 跨录制解码权重汇总

**一句话总结：**沿用单记录 S14/S10 设置，对所选录制独立拟合，再逐通道等权计算 |wx|、|wy|、norm 的 median 和 average，共六张图。

下方为 Elec# 0，上方为 127；Shank 从左到右为 1–8。所有图使用 hot_r 和六图统一的自动范围 色条，高值深色，零权重白色，未观测通道灰色。没有 position groups 副图。

## 图 1：vx weighting median

### 计算公式
**符号**
- w：每个 run 的绝对权重 |wx|。N：该通道实际传输的录制数。
**步骤**
1. 用 S14 设置独立拟合每份所选录制。用 Channel# 对齐同一个通道，不按接收列号对齐。
2. 排除未传输的缺失值，保留已传输恒定通道的零系数，然后对该通道计算 中位数。每份录制等权。
3. 按当前新天枢 mapping 绘图，色条六图统一的自动范围。超过统一上限 只颜色饱和，CSV 数值不截断。

### 结果解读
- **通道热力图**：显示每个位点跨所选录制的 median 权重幅度。
- **固定色条**：高值深、低值浅；灰色表示所有所选录制均未传输该通道。

### 质量评价标准
- **通道热力图**：CSV 的 n_runs_observed 给出实际样本数，覆盖少的通道需谨慎比较。零权重并不证明没有解码信息。
- **固定色条**：相同颜色表示相同数值，但权重不是独立贡献或泛化准确率。Elec# 不是毫米解剖深度。

## 注意事项

norm 先在各 run 内计算再汇总，不能用跨 run 的 wx、wy 均值或中位数重新求 norm。每份勾选的录制算一个样本；同一天不额外平均，不按 bin 数加权。一次选择多个片段时，每个片段分别计为一份录制。新模块自动继承 S14 的模型与权重单位及 S10 的训练参数，不混合不同口径。


色条上限由六张统计图的共同最大值向上取合适刻度确定，覆盖全部统计值；不同选择范围重新确定上限，但同一次汇总的六图始终一致。单记录 S14 仍固定 0–25。
