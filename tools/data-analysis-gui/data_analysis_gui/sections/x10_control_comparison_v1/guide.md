# 脑控与离线摇杆 BPS / TTT 配置对照

选择记录的最早至最晚日期，读取这个范围的全部正式编号 run（包含只有 CSV 的日期），排除 20261116。
蓝色圆点为脑控，橙色方点为离线摇杆。按日期、任务、run 对应导出的 Excel；相同配置也完整保留。
Grid 和 CO8 独立绘图。BPS 为 60 秒有效尝试时间窗口、1 秒步长；长 run 从 60 秒开始，只有整 run 不足 60 秒才折算。
TTT 只统计成功 trial，每 trial 一次，包含 dwell；中位数与 IQR。不同 Grid、dwell、辅助、模型设置应分组比较。
未找到独立 CSV 的 run 不复制其他 run 数据。模型字段仅为保存设置，不证明实际更新成功。
